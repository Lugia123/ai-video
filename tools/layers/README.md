# tools/layers：2.5D 素材管线

MV（`episodes/mv-pdoom`）的技术路线是：背景切成多个景深平面、角色拆成骨骼纸偶，一起放进 three.js 舞台里用真实相机运镜（见 TREATMENT.md 第 5 节）。这里是把**一张定稿画**变成这两类素材的脚本。

| 脚本 | 作用 |
| --- | --- |
| `depth.py` | 单独跑 Depth Anything V2 出深度图（调参时看用） |
| `bg_layers.py` | 背景：深度 + 千问「逐层剥离」→ 分层 RGBA + `layers.json` |
| `check_layers.py` | 背景自查：叠回原画算误差、错开模拟视差查空洞/重影 |
| `puppet.py` | 角色：T 字立绘 → 部件 PNG + `puppet.json` |
| `puppet_pose.py` | 角色自查：按 `poses.json` 摆姿势，出对比图并数关节缝洞 |
| `auto_joints.py` | T 字立绘自动估关节（写回 rig.config.json，再目测核对） |
| `face_swap.py` | 把参考图的表情贴到立绘上（SIFT 对齐 + 椭圆羽化），千问换表情不稳时用 |
| `edit.py` | 编辑引擎统一入口：千问（默认）/ `EDIT_ENGINE=dt` 本机 Draw Things / `EDIT_ENGINE=none` 干跑 |

环境：`torch`（MPS）+ `transformers` + `opencv` + `Pillow` + `scipy`。
千问模型用 `tools/dt/qwen_edit.py` 的默认值（现为 `qwen-image-edit-plus-2025-12-15`；不带日期的别名在本账号 403）。难删的层可在配置里单独写 `"model": "qwen-image-edit-max"`。千问 Key 用 `set -a; . ~/.config/tts-keys; set +a` 载入。千问结果都缓存在各自的 `_work/`，重跑不会再花钱；想重抽就删掉对应文件或换 `--seed`。

## A. 背景切层（样例 `episodes/mv-pdoom/art/layers/whale-city/`）

```bash
set -a; . ~/.config/tts-keys; set +a
python3 tools/layers/bg_layers.py episodes/mv-pdoom/art/layers/<场景>/scene.json [--seed 23]
python3 tools/layers/check_layers.py episodes/mv-pdoom/art/layers/<场景>
```

### 做法：逐层剥离

从最前层往后，每一步：

1. 对当前底图重跑深度（前面的层已被移除，所以这一层原本被挡住的部分已经画完整了）。
2. 让千问「移除这一层」，输出先做 **ECC 仿射对齐**（千问会把整张图平移约 8–11px），再算前后的 Lab 差异。**差异本身就是这一层的 mask**，深度只用来约束（比如「只要近处的」）。这比按颜色/深度阈值硬切干净得多：云顶、天线这些都能完整拿到。
3. 这一层 PNG = 当前底图，alpha = mask 往外扩 3px，再羽化 1.5px。
4. 千问的像素先按周边一圈做线性配色，**只贴回 mask 外扩 3px 的范围**，得到下一层的底图。原画里本来看得见的地方保持原像素，所以叠回去几乎无损。

最后一层（天空）不透明。某层不写 `remove` 时，后一层直接沿用同一张底图（海面在天空前面，而且海面区域会被海面层完全盖住，就没必要再补画）。

每层 PNG 四周都**镜像外扩 `pad` 像素**（默认 64），给相机平移留余量。

### scene.json 写法（照 whale-city 改）

```json
{"src": "../../approved/01-whale-city-2.png", "fov": 35, "pad": 64,
 "layers": [
  {"name": "03-near-clouds", "rule": "(d>0.5)&(y>0.62)", "grow_rule": "y>0.72", "grow": 3,
   "remove": "移除画面最下方前景的近处白色云朵……其余保持完全不变"},
  {"name": "02-whale-city", "rule": "rel>0.1", "thin_rule": "y<0.62", "ref": true, "z": 0, "grow": 3,
   "min_area": 20000, "remove": "删除画面中央那头巨大的机械鲸鱼……整头鲸鱼必须完全消失"},
  {"name": "01-sea", "rule": "(d>0.2)&(y>0.6)", "grow": 2},
  {"name": "00-sky"}]}
```

- `rule` 里能用的变量：`d` 深度（0 远…1 近）、`rel` 比本行 15 分位高出多少（地面/海面上「凸起来的东西」，拿来抠主体很好用）、`D` 千问前后的差异、`x,y` 归一化坐标、`r,g,b,lum,sat`。
- `grow_rule`：满足它的差异区域里，凡是和种子相连的整块都并进来（滞后阈值）。近云的云顶深度偏远，靠这个补回来。
- `thin_rule`：满足它的差异区域里，宽度小于 `thin_px` 的细条和面积小于 `thin_area` 的碎块也并进来，但只要离主体 80px 以内的。天线、电线、晾衣绳靠这个。
- `ref: true` 的层放在 z=0，缩放为 1；其他层的 z 按深度中位数换算（距离 ∝ 1/视差，限制在参考距离的 0.5–4 倍），也可以手写 `z`。

### 进阶选项（rooftop-spirit 里用到）

- `seed` / `model`：给单层单独指定千问的种子和模型。
- `matte: "diff"` + `matte_range: [lo, hi]`：差分抠像。alpha = |原图 − 移除后| 的幅度映射到 0–1，颜色做反预乘。光雾、发光体、软边云用它：半透明边缘干净，单独缩放做呼吸动画也不会带出背后的云，叠回仍是精确的。
- `fill: "global"` + `region`：规则区内整片换成千问的结果。先用「差异最小的 30% 像素」稳健拟合各通道的线性配色，再配合 `matte: "diff"` 抠出区内所有与它不同的东西。用于「天空 + 远云」：千问删云时常把整片天空重画、换了色调，局部贴回会出现色块或方盒边。
- `fill: "inpaint"`：千问只用来定 mask，补画改用 OpenCV 在低分辨率上 inpaint。适合小块平滑背景；**大块积云不适用**（mask 抓不全时会糊成一片）。
- **ECC 保护**：仿射结果出现剪切/缩放 > 2% 或平移 > 30px 时退回纯平移（大面积被移除时，仿射会发散）。
- **每层深度图** `<层>.depth.png`：16-bit，与层 PNG 同尺寸（含 pad），是这一步底图的深度；层外用最近的层内值外推，避免位移时边缘被拉扯。`layers.json` 里有 `depth_file` 和 `depth_range`（层内深度的最小/最大值，0–1）。每步的深度都是单独归一化的，**不同层之间的数值不可比**，只用于层内起伏。
- **多层场景要手写 `z`**：自动 z 按各层深度中位数估算，但每步底图的深度是单独归一化的。rooftop 就排错了（浮岛排到了屋顶前面）。超过 4 层的场景，每层都手写 z。

### layers.json

`camera`：竖直 fov，相机在 `(0,0,z)` 看向原点，世界单位 = 原图像素。每层有 `file / order / z / scale / bbox / depth_median`。three.js 里每层做一块 `(W+2pad)×(H+2pad)` 的平面，放在 z 处、乘上 `scale`，在默认相机下就和原画逐像素对齐；相机一动就有视差。

### whale-city 结果

4 层：`00-sky`、`01-sea`、`02-whale-city`、`03-near-clouds`。千问一共调 2 次（近云、鲸城），调参中重抽了 2 次。

- 叠回误差：平均 **0.30/255**，99 分位 11.4/255，差值 >16 的像素占 0.64%（都在层边缘的羽化带）→ `check-recomposite.jpg`
- 视差：前层 40px、鲸城 32px、海面 25px、天空不动，四个方向**空洞 0%**，鲸鱼没有重影 → `check-parallax.jpg`

### 坑

1. **千问会整体平移输出**（这张图约 8–11px）。不对齐就直接做差异或贴回，全图都会被算成「变了」，接缝处还会错位。先用全图粗对齐，找出变化区，再只用没变的区域精对齐。
2. **千问常常不照做**：第一次让它「移除鲸鱼和城」，它只删了城、鲸鱼还留着。提示词要写死「整头鲸鱼必须完全消失，一点不留」，并且把要保留的东西逐个点名。每一步都要看 `_work/plate-after-*.png`。
3. **它会顺手改别的东西**：移除近云时连地平线上的中景云也一起删了。所以差异 mask 一定要加深度/位置约束，不能全收。
4. **补画区比层 alpha 宽时，误差会翻好几倍**：两者之间那圈露出的是千问的像素而不是原画。补画区只比 alpha 宽 3px 就够了（平均误差从 1.18 降到 0.30）。
5. 纯靠颜色/深度阈值抠云，要么漏掉云顶，要么吃进鲸鱼腹部的白边；改用差异 mask 以后这些问题都没了。
6. 本机的 torchaudio 和 torch 版本对不上，`transformers.pipeline` 一 import 就崩。脚本里把 torchaudio 屏蔽掉，直接用 `AutoModelForDepthEstimation`。
7. 天空底图上可能残留很淡的电线痕迹（千问没擦干净，差异又太弱没被收进 mask）。大幅运镜时，要看视差图里原来有细物的位置。

### rooftop-spirit 结果（#909）

8 层，按 z 从前到后：`07-near-leaves`(+450)、`06-pots`(+90，含卫星锅和空调)、`04-roof`(0，小屋+地面)、`05-railing`(−160，栏杆+串灯)、`03-spirit`(−1500，神灵光雾+蝴蝶，差分抠像)、`02-islands`(−2300，浮岛+左下楼)、`01-far-clouds`(−3100，积云+远云，差分抠像)、`00-sky`。每层都有 `.depth.png`。

- 叠回误差：平均 **0.94/255**，99 分位 14.3，>16 的像素占 0.79%。比鲸城的 0.30 高，因为两个差分抠像层的半透明边缘多。
- 视差：四个方向**空洞 0%**，没有重影。

坑：
- 删栏杆第一次只删了左边的墙沿，要把「中间整排竖条护栏 + 串灯」点名。
- 「AI」霓虹字母深度偏远，没进 mask，原像素留成了粉色残影。规则要写成「右上区域里凡是改动过的都算」。
- 删积云时千问会把整片天空和旁边的小云一起重画、换色调，最后改用 `fill: global` + 差分抠像。
- 云海里还残留几个很小的栏杆桩和植物碎片（前几步千问没删干净，被前景层挡着，只有大幅运镜时才会露出来）。

### 以后 30+ 张背景怎么做

复制 `whale-city/scene.json`，改 `src` 和每层的 `remove` 提示词 → 跑 `bg_layers.py` → 看 `_work/plate-after-*.png` 和 `mask-*.png` → 调 `rule`，或者删掉缓存重抽 → 跑 `check_layers.py`。按经验，一张图要调 2–4 轮。

## B. 角色骨骼纸偶（样例 `episodes/cast-cyber-girl/cats/puppet/orange/`）

```bash
set -a; . ~/.config/tts-keys; set +a
python3 tools/layers/puppet.py episodes/cast-cyber-girl/cats/puppet/<花色>/rig.config.json
python3 tools/layers/puppet_pose.py episodes/cast-cyber-girl/cats/puppet/<花色>      # 默认读 ../poses.json
```

### 做法

输入是白底的 T 字正面立绘（`turnaround/<花色>/front-tpose.png`）。

1. **抠图**：与画面边框连通的近白像素算背景（角色内部的白毛、鞋底、眼睛高光被描线围住，不受影响）。边缘软化按「离白色多远」计算。
2. **补遮挡的底图（千问）**：
   - `noarms`：去掉双臂，肩膀收成圆润的肩线 → 躯干层用它，手臂转下来时肩膀处不会露出袖子残茬。
   - `nolegs`：去掉裤腿，把尾巴根完整画出来 → 尾巴层用它。
   - 道具（荧光棒）让千问参考 `design/<花色>.png` 单独画在白底上，再抠出来，按 `length` 缩放。
   - 每张底图都用 `align_rows`（两张图都没改动的行区间）做 ECC 对齐。
3. **分区**：在 `joints` 里写 20 来个关节点（原图像素坐标）。某像素投影落在骨段 [0,1] 之内（末端骨段可以超出末关节）、并且离骨段的距离小于 `r`，就是候选，归给最近的骨段；剩下的前景按 `trunk` 行区间分给头、躯干、骨盆。`rule` 在归属竞争阶段就生效，比如尾巴 `x<328`，不许它抢裤腿的描边。
4. **关节不露缝**：子部件在枢轴处再并进一个 `disc` 圆盘（像素来自同一张图）。转动时这个圆盘一直盖在关节上。z 序：尾巴 < 小腿 < 大腿 < 骨盆 < 躯干 < 道具 < 前臂 < 上臂 < 头。

### puppet.json

每个部件：`file`、`parent`、`z`、`origin`（部件 PNG 左上角在原画布上的位置）、`pivot`（原画布坐标）、`pivot_local`。角度正值 = 屏幕上顺时针；世界变换 = 父变换 · T(pivot) · R(θ) · T(−pivot)，按 z 从小到大画。根节点是 `pelvis`，姿势里的 `root:[dx,dy]` 表示整体平移。`_l/_r` 指**画面**左右，不是角色自己的左右。

`cats/puppet/poses.json` 是 5 只猫共用的舞姿（骨骼名都一样）。

### orange 结果

14 个部件：头、躯干、骨盆、左右上臂、左右前臂+爪、左右大腿、左右小腿+鞋、尾巴、左右荧光棒。4 个舞姿（双手举高、左摆、右摆、蹲跳）检测到的**关节缝洞都是 0** → `check-poses.jpg`（上排白底，下排棋盘底，用来看 alpha 漏洞和白边）。

### 坑

1. **千问「去手臂」经常不照做**：第一次只是把手臂重画了一遍。换了说法（「擦掉，变成白色背景，像截去手臂的人台模特」）才成功。英文提示词那次把短款卫衣改成了长 T 恤，不能用。
2. **「去腿」会画出短裤加光腿**，不是真的去掉腿。所以骨盆层还是用原图，只从这张底图里拿尾巴。
3. **抠图软边的 bug**：边缘带如果给 `max(soft, 0.5)`，每个部件都会带一圈半透明白边，尾巴根那里最明显。软边只能按离白色的距离算。
4. **骨段半径会抢像素**：尾巴的胶囊半径压到了裤腿描边上，大腿左边缘就少了一块，一转就是个白楔子。约束要在归属竞争阶段生效，不能等出图时再裁。
5. **躯干顶部被头挡住的那几行会带上胡须尖**，头一歪就露出第二套胡须。所以躯干顶部要限制 x 范围（`rule`）。
6. T 字立绘里爪子是张开的，荧光棒只能摆在掌后，看起来不像真的握着。以后的立绘最好让千问画成握拳，或者直接用握着道具的版本。
7. 荧光棒的发光边被抠成一圈浅色轮廓，在深色背景上能看出来。需要的话把道具的 `cutout` 阈值调低，或者给它单独做一个 additive 发光层。

### #909：5 只猫 + 主角全身

- **关节自动估**：`auto_joints.py` 用轮廓找臂展行、躯干边、手尖（肘/腕按 0.37/0.755 比例），用衣服颜色找颈（中线左侧 50px 处卫衣段的顶，避开胸前闪电）、腰（下摆）、胯（裤腰到裤裆的 45%）、脚（鞋底，只在胯以下找黄色），尾巴用测地距离取 4 个中轴点。在橘猫上和手标差 ≤10px。跑完一定要看 `_work/_joints.png`。
- **蓝灰/奶牛换微笑脸**：千问多参考图编辑总把「图2」当底图（直接改了设计图，姿势全变）；对调顺序或只用文字，也改不成目标表情。最后用 `face_swap.py` 把 `_smile/*-soft-*.png` 的脸用 SIFT 对齐后羽化贴上。奶牛两张图的黑白花纹分布不同，只贴嘴部。产物是 `cats/turnaround/{bluegray,tuxedo}/front-tpose-smile.png`。
- **握棒**：再加一张 `grip` 底图（千问：双手握拳、各竖握一根短荧光棒），前臂从它取，`box` 把伸出胶囊外的整根棒并进前臂。**荧光棒成为前臂的一部分**，不再单独做道具层，所以一定握在手里。`halo: true`：从背景出发、穿过浅色像素（min≥170）能连到的区域按离白色的距离给半透明 alpha，并对白色反预乘，发光晕在任何背景上都是纯色辉光，不发灰。白爪被描线围住，不受影响。第一次荧光棒画得太长（约两个头长），提示词改成「前臂一半长、手指粗」。
- **尾巴约束**：`rule: "~cloth"`（尾巴不许占衣服颜色的像素），通用于尾巴在腿旁或腿间的各种猫。
- **主角**：底图 `nohair`（长发改成波波头，肩部补全）→ `noarms` 在 `nohair` 基础上链式生成（`from`）。躯干取 `noarms`，并在肩枢轴外侧裁掉，否则手臂放下时圆肩会突出来；上臂取 `nohair`（袖子上没有头发）；前臂取 `grip`；头取原图。`hair_back` = 原图里棕色头发（`select: "hair & ..."`），z=−1 挂在头下；`hair_front` = 额前刘海，z=8.5，压在眼口之上。
- **眼口替换**（`overlays`）：`closeup/layers/{eyes,mouth}/*.png` 用 3 点相似变换（近景两眼+嘴 → 全身两眼+嘴，眼睛再缩 0.93）变换过来，裁成 `eyes/<状态>.png`（6 个）和 `mouth/<状态>.png`（8 个）。puppet.json 里 `eyes`、`mouth` 两个部件带 `states`，渲染时换 `file` 即可。
- **缝洞检测改进**：原来的检测会把胡须之间、尾巴和裤腿之间、手叉腰这些正常空隙也算进去。现在只看带 `disc` 的真关节（尾巴、道具、眼口不算），并把洞中心按最近关节的父、子部件逆变换回静止姿势，两边都落在身体里才算缝。部件内部 < 200px 的小洞会自动补实：底图描线处偶尔有细白缝连到外面，抠图时被当成透明，转动后会露出来。
- 结果：orange / white / calico / bluegray / tuxedo / girl 六个纸偶的 4 个舞姿**缝洞都是 0**，荧光棒都握在拳里 → 各自的 `check-poses.jpg`。

### 以后 5 只猫 + 主角全身怎么做
