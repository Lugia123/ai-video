# 《移植不是翻译》讲解员：第二轮候选

## 用户怎么说
现在的橙色方块小人（`assets/lib/box-buddy.js`）有 Claude 吉祥物的影子，要换一个**原创**形象。第一轮 5 个候选（`assets/characters/candidates/compare-all.png`）被否：「还是框死在了 claude 的基础形象上，别人一看就有 claude 的影子，拓展想想」。

## 第一轮为什么失败（必须读懂再动手）
看 compare-all.png 的剪影那一排：5 个候选全是同一副骨架——**一个块状身子 + 左右各伸出一根水平短棍小手（末端圆/方块） + 下面两条短腿 + 身子正面两个黑豆眼、没有嘴或只有小嘴**。只是把身子换成线轴、剪刀、胶带、风筝、山。这个「身子即脸、侧伸短棍手、短腿、豆豆眼」的结构本身就是 Claude 吉祥物的识别点，换什么外形都还是它。
根源是当时要求「和 createBuddy 接口一致、手的位置相同、state(t) 全等」，把骨架锁死了。**这一轮取消这个约束。**

## 这一轮的硬性禁区（任何一条命中就不交）
- 身子就是脸（脸长在躯干正面、没有独立的头）。
- 从身体两侧水平伸出的短棍手 / 浮空圆球手。
- 方块、长方体、积木、像素感的身子；橙色、赤陶色、珊瑚色为主色。
- 只有两个豆豆眼的极简脸。
- 也别像其他已知吉祥物（Duolingo 猫头鹰、Android 机器人、GitHub Octocat、Go 地鼠、Rust 螃蟹、小黄人、Kirby、Totoro……）。

## 往哪拓展（每个候选在下面至少两个维度上和第一轮不同）
- **身体结构**：有独立的头和身子；比例可以头大身小、细长、矮胖、四足、无腿（飘、滚、弹）、有尾巴/翅膀/触角。
- **表情系统**：有嘴、眉毛、表情变化大；或者完全不用五官、靠肢体和剪影表演。
- **物种/类别**：小动物、小怪物、拟人小孩、精灵、机械但不方、植物、天气现象……都可以；不必和主题沾边（用户明确说「纯粹就是想换」）。
- **画法**：仍要搭系列的纸剪 / 蜡笔手绘画风（米白纸底、毛边描边、蜡笔排线），在米白纸上醒目。

## 接口
不要求和 createBuddy 骨架一致。要求：同样的调用方式（`createBuddy(ctx, { path, acts })`、`draw(t)`、`state(t)`），支持同一套 act 名（look / point / startle / thumbs / shake / question / nod / hop / droop / knife），但每个动作用**它自己的身体**演（没有手的可以用尾巴/耳朵/头指；point 必须让观众看得出指向哪）。画面是 t 的纯函数。大小大致占地 160–240 px 高。选中以后各集的镜头允许微调，这一步不考虑替换成本。

## 交付（写在你自己的目录 `assets/characters/candidates-v2/<你的字母>/`）
- 每个候选：设定图（正面 + 3/4 侧面 + 六个姿势：idle / point / question / startle / thumbs / droop），写「是什么、一句话性格、标志特征、和 Claude 吉祥物差在哪（具体到结构）」。
- 一张你的候选并排的剪影对比图，**最左放 Claude 式参照（现在的方块小人）**——剪影要一眼看得出不是一家。
- 一段 6–8 秒的动作小样 mp4（走两步 + 指 + 疑问 + 吓一跳 + 点赞 + 泄气）。
- 代码 `assets/lib/buddy-candidates-v2/<名字>.js`。
- 不改任何一集、不改 box-buddy.js、不生成千问图、不 commit。
