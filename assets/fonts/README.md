# assets/fonts — 本地开源字体

全部来自 Google Fonts 官方仓库 <https://github.com/google/fonts>（`ofl/` 目录），SIL Open Font License 1.1，
许可全文在各子目录的 `OFL.txt`。下载日期 2026-09-29（fraunces / bungee / kalam 为同日第二批，给 MV 的吉卜力 + 复古招牌风格用）。可自由用于视频画面（含商用），不得单独售卖字体文件。

| 目录 | 文件 | 用途 | 来源路径 |
|---|---|---|---|
| anton/ | Anton-Regular.ttf | 粗压缩无衬线：印章、招牌、大字 | ofl/anton |
| bebasneue/ | BebasNeue-Regular.ttf | 全大写窄体：翻牌、栅栏挂牌 | ofl/bebasneue |
| caveat/ | Caveat-Variable.ttf（原名 `Caveat[wght].ttf`，可变字重 400–700） | 手写体：手写浮现、毛线 | ofl/caveat |
| pacifico/ | Pacifico-Regular.ttf | 圆润连笔：霓虹灯牌 | ofl/pacifico |
| sharetechmono/ | ShareTechMono-Regular.ttf | 等宽科技感：HUD、电路 | ofl/sharetechmono |
| fraunces/ | Fraunces-Variable.ttf（原名 `Fraunces[SOFT,WONK,opsz,wght].ttf`，可变：字重 100–900、SOFT 圆润度、WONK 歪扭） | 柔和复古故事书衬线：木牌、纸条标题 | ofl/fraunces |
| bungee/ | Bungee-Regular.ttf | 复古招牌 / 霓虹灯箱字 | ofl/bungee |
| kalam/ | Kalam-Bold.ttf | 圆珠笔手写：纸条、便签 | ofl/kalam |
