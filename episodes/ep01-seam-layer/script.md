## s01
旁白：想象一下，把同一个软件搬到 Windows 电脑上。有人得重写两万三千多行代码，有人却只改了二十行。这是怎么做到的？
画面：第 0 帧就有画面：左边纸代码山一路长高，计数冲到 23,669，「两万三千多行代码」时轰然塌下，小人被埋，又从纸堆里探出头；「只改了二十行」时右侧飘下一张「20 行」薄纸。「怎么做到的？」小人看看左右，头顶问号。

## s02
旁白：不是谁的技术更牛，而是看你从哪里“下刀”，把软件切开。这神奇的一刀该怎么切？我们现在就来看。
画面：小人抽出纸刀；「下刀」时镜头俯冲到分层纸板的架构图，刀在层与层之间比划。大字「从哪里下刀？」。说完后 1.5s 无配音系列字卡：《移植不是翻译》第 1 集 · 接缝选在哪一层。

## s03
旁白：把软件搬到另一个系统，叫“移植”。就好比把软件切成两半：一半不变，一半重写。切开的口子，就叫“接缝”。
画面：分层纸板：「一半不变」时核心 + C API 变绿，「一半重写」时界面层变红；「接缝」时切口亮起红虚线。大字「接缝」。

## s04
旁白：接缝就像插头和插座。形状对上了，插进去就能用。
画面：纸剪的插头滑向插座，「插进去就能用」时插进去，咔哒，绿勾。小人竖手。

## s05
旁白：很多人的第一反应是：找份差不多的代码直接抄。可就算是同一种语言写的，也不能直接搬。关键要看，这些代码都在“找谁帮忙”。
画面：两个纸窗口并排：左「Linux 版」满是代码，右「Windows 版」空白，中间一个「直接抄？」的箭头；「找谁帮忙」时光标点出 gtk. / adw.。大字「同语言 ≠ 能直接搬」。

## s06
旁白：来看个真实的故事。Polter 是一款软件，就是黑客电影里那种敲命令的黑窗口。它在 Linux 上的界面，足足有两万三千多行代码。
画面：从一张 .zig 纸片开始，镜头急速拉远，露出整座文件山，小人被吓一跳；黑窗口里敲行数统计命令，数字滚到 23,669。

## s07
旁白：问题来了：这些代码找的帮手，全是 Linux 专属的“工具箱”，有些在 Windows 上根本没有。硬搬过去，就全废了。
画面：纸质编辑器：gtk / glib / gdk / adw / gio 的调用被红笔圈出，飞进一只标着「Linux 工具箱」的纸工具箱；adw 盖上「Windows 上没有」；「全废了」时每行划掉变灰。

## s08
旁白：那在 Windows 上从头重写？光是打字输入这一块，就得像拼图一样拼一堆底层零件。用微软自带的工具呢？行是行，但开发都习惯用 Mac，所以也不太好。
画面：两张方案卡片：「从头重写」卡片上的拼图块拼不拢，被红笔划掉；「微软自带的工具」卡片旁一台 Mac 笔记本，打上「不太好」的章。小人摇头、泄气。

## s09
旁白：怎么破局？他们用了苹果版早就走通的办法：软件的核心，只往外留一个很基础的接口，就像一个大家都认的“万能插座”。
画面：大字「怎么破局？」。C API 插座亮起，标签「万能插座」；苹果版外壳的线上跑一道绿光；镜头沿连线平移到右侧空位。

## s10
旁白：有了这个插座，Windows 版只要做个新插头插上去。插座这边，只多了一个窗口编号，大概二十行代码。
画面：Windows 插头沿线过来插进插座，咔；纸质编辑器里平台联合体多出一行 `struct { void* hwnd; } windows;`；「二十行代码」时出现大字「插座这边 ≈ 20 行」。

## s11
旁白：这就是开头那“二十行”的秘密。
画面：回到开场构图：左边塌下的纸山（23,669），右边一张薄纸（20）；小人把插头插上，咔。

## s12
旁白：所以记住：找接缝，要选规矩最少、别人已经走通的地方。下次给代码搬家前，先看一看：它到底在找谁帮忙。
画面：原则字卡：「规矩最少」「别人已经走通」划线；小人点头、竖手。说完 0.5s 后切结尾字卡（下一集预告，1.5s），干脆结束。
