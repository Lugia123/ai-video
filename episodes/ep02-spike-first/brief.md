# ep02：先打掉最大的未知数

- **标题（封面大字，用户定）**：三个月全白干？先做最没把握的那件事
  - 备选：①「搭了三个月才发现做不出来？先试最没底的那块」 ②「最没把握的事，第一天就去试」
  - v1 草稿标题「十件事，有一件做不成就全白干——先做哪件？」已弃用（钩子改成「三个月全白干」）。
- **封面画面**：一座搭到一半的纸架子（每块写「第 N 周」）轰然塌掉，底层红色「？」块碎成三片；橙色方块小人在废墟边举着一张写「先试这个」的黄色小纸条。视频前 3 秒兑现同一个画面（0.45s 最后一块落顶 → 0.95s 红块裂开 → 1.35s 整座塌下）。
- **一句话目标**：看完这集，观众知道动手前要先把「读代码答不了、做不成就全白干」的那件事挑出来，用一小段试验代码先试掉它，而不是按顺序一件件做。
- **受众**：对软件开发好奇的初中生及以上；做跨平台客户端的开发者也能看。旁白按初一阅读水平写，口吻学 ep01 用户定稿（`../ep01-seam-layer/script-v2-final-voice.txt`）。
- **时长**：实测 123.66 秒（旁白定稿 13 段，见 `script-v2-final-voice.txt`），横版 1920×1080 / 30fps。
- **视觉风格**：沿用 ep01（纸质 UI + 橙色方块小人 + `assets/lib`）。4 处运镜：①开场贴近纸架子，塌下时拉远 + 震；②从设计文档俯冲进「那一条」；③从 Mac 横移到 Windows 真机；④推近到光标与候选框。
- **配音**：千问 `qwen3-tts-instruct-flash` · 音色 Maia（同 ep01）。
- **素材来源**：`source/series-script.md`（下称「原稿」，复制自 ep01）第 2 集（:82–123）。只用原稿「事实核对」表（:113–121）里已核的事实。
