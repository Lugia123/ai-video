## s01
旁白：屏幕上一行绿字：编译通过了！可一放到真的 Windows 电脑上跑，二十九个测试，当场挂了。
画面：【钩子 0–3s】第 0 帧：纸质终端窗口里一行大绿字「编译通过 ✓」，橙色方块小人在旁边举小旗欢呼。「真的 Windows 电脑」时纸窗口沿弧线飞进一台纸质 Windows 显示器；「二十九个」时屏幕哗地铺满红叉，红色大字「29 个失败」砸下来，小人的小旗耷拉下来。

## s02
旁白：原来，“编得过”只是第一道门。一个程序要真能用，得连过四道门：编译、链接、运行、绘制。
画面：镜头拉远：绿字其实贴在第一扇纸门上，门后一条走廊，还有三扇灰门。四扇门依次亮起门牌「编译 / 链接 / 运行 / 绘制」。说完后 1.5s 无配音系列字卡：《移植不是翻译》第 5 集 · 可移植性分层。

## s03
旁白：编译，是把代码翻成电脑懂的话；链接，是把零件拼成一个程序；运行，是真跑起来；绘制，是把画面画到屏幕上。
画面：四扇门各配一个小动画，一次只亮一扇：代码纸 → 机器码纸条；几个零件咔咔拼成一个程序盒；程序盒跳动起来；纸窗口里画出一行字。

## s04
旁白：麻烦在于，每一道门，都把后面的问题挡住了。不推开这一道，你根本看不见下一道后面有什么。
画面：小人站在第一扇门前，门后一片灰；门推开一条缝，才露出第二扇门上贴着的「？」。

## s05
旁白：Polter 这款软件搬 Windows 时，第一次编译，只报了几个错，全在自己写的代码里。修好之后，拼零件时又缺了一块，也补上了。前两道门，都过了。
画面：纸质编译输出：几条红色错误，全部指向同一个文件夹（标「自己写的代码」）；小人一条条撕掉。一个零件盒缺一角，补上。「编译」「链接」两扇门打勾推开。

## s06
旁白：直到测试第一次在真的 Windows 电脑上跑：二十九个失败。将近一半，卡在同一件事上：程序之间传话用的一条通道。
画面：【再抓回来 ~25%】第三扇门「运行」推开：29 个红叉排成一排，其中 14 个一起亮起、飞到一起，拧成一根断掉的纸管子，标签「传话通道」。

## s07
旁白：他们一层一层往下挖。第一层：有个开关，在编译时就悄悄把这条通道关掉了。
画面：运镜：镜头沿断掉的纸管往下俯冲，穿过第一层地板；地下一个拨到「关」的纸开关。

## s08
旁白：把开关打开，第一个测试就崩了。别慌，这不是退步，是又挖深了一层。
画面：小人拨开开关——「咔」一声，第一个测试纸卡片当场碎裂；小人愣了一下，拍拍灰，在墙上画一道刻度「第 2 层」。

## s09
旁白：再往下挖，毛病出在编程语言自带的工具箱里：有一句代码，没守住它自己立的规矩。
画面：【大场面 ~50%】继续俯冲到最底层：一个巨大的纸工具箱，箱盖上贴着一张「规矩」纸条；箱子里一行代码亮红，和规矩纸条之间拉出一根红线，打叉。

## s10
旁白：最后，他们换了一条路：改用 Windows 自己的传话管道。要传的话，一个字都不用改；管道只有你自己能用，也不开谁都能连进来的口子。
画面：断掉的纸管被拆下，换上一根新管道（标「Windows 自己的传话管道」）；管道里流过的小纸条内容完全不变。旁边一扇通往外面的小门被打叉封上，管口挂一把只有小人才有钥匙的小锁。

## s11
旁白：可修没修好，不能只跑一次就算。就算毛病还在，连跑三次全过的运气，往宽了算也有三成；跑五次，就只剩一成多。
画面：【再抓回来 ~75%】一排骰子/硬币式的「跑一次」卡片：三张全绿时，旁边一根运气条停在「≈30%」；再翻两张，运气条缩到「≈13%」。

## s12
旁白：所以他们跑五次。交出去的版本，五次全过。
画面：五张卡片依次翻绿，「5/5」盖章；第三扇门「运行」稳稳打勾。

## s13
旁白：下次报告进度，别只说“通过了”。要说清楚：通过到了第几道门。
画面：一张状态纸条上的「通过了 ✓」被划掉，改写成四格：「编译 ✓ / 链接 ✓ / 运行 ✓ / 绘制 ?」。

## s14
旁白：回到开头那行绿字：它说的是真话，可它只管第一道门。
画面：【收尾】回到开头那行「编译通过 ✓」，镜头拉远，它只贴在第一扇门上，后面三扇门一扇扇亮起。说完停 ≥2.5s，结尾字卡 ≥2.5s，干脆结束。
