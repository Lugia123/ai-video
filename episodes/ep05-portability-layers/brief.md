# ep05：可移植性分层：编译 → 链接 → 运行 → 绘制

- **标题（封面大字，待用户定）**：编译通过了，为什么还是跑不起来？
  - 备选：①「“编译通过”，是最危险的一句话」 ②「程序要过四道门，你只过了第一道」
- **封面画面**：纸质走廊里四扇门，第一扇绿门敞开、门上贴「编译 ✓」；后面三扇灰门，最远那扇门缝里透出红光和「29 个失败」；橙色方块小人站在第一扇门口举着庆祝小旗，回头一愣。视频前 3 秒兑现同一个画面（0s 绿字「编译通过 ✓」+ 小人欢呼 → ~2s 红叉铺满、「29 个失败」砸下）。
- **一句话目标**：看完这集，观众知道「编得过」只是四层里的第一层，每一层都会挡住下一层的问题；报告进度时要说「通过到第几层」，对时好时坏的问题要多跑几次，算清「碰巧全过」的可能。
- **受众**：对软件开发好奇的初中生及以上；做跨平台客户端的开发者也能看。旁白按初一阅读水平写，口吻学 ep01/ep02 用户定稿（`../ep01-seam-layer/script-v2-final-voice.txt`、`../ep02-spike-first/script-v2-final-voice.txt`）。
- **时长**：目标 90–140 秒。旁白 14 段、约 519 字。按 4.5 字/秒 + 句间 0.6 / 段间 1.2–1.5 / 问句 +0.3 / 系列字卡 2 / 结尾 5.6 秒粗估 ≈ 150 秒；但同一算法算 ep02 定稿得 149.9 秒、实测 123.66 秒，按此校准 **≈ 123 秒**。横版 1920×1080 / 30fps。
- **视觉风格**：沿用 ep01/ep02（纸质 UI + 橙色方块小人 + `assets/lib`）。主比喻换成「四道门」（原稿是四层楼板；门更好表达「挡住后面」）。3 处运镜：①开场纸窗口飞进 Windows 显示器；②拉远露出门后走廊；③沿断掉的「传话通道」往下俯冲三层。
- **配音**：千问 `qwen3-tts-instruct-flash` · 音色 Maia（同 ep01/ep02）。
- **素材来源**：`source/series-script.md`（下称「原稿」，复制自 ep01）第 5 集（:222–272）。只用原稿「事实核对」表（:257–269）里已核的事实。
