# screen-clips：舞台大屏素材库（#1055）

舞台 LED 大屏上放的她的动作片段。本地图生视频（Wan 2.2 I2V，Apache 2.0）生成，首帧 / 尾帧由本地 `/edit` 喂设定图出，白底。逐帧「换底」：不做二值抠图，白的程度软过渡成透明，人物内部（眼白、牙、手）用 BiRefNet 保护，边缘压一圈深色；残留的小毛边靠大屏的 LED 像素格、泛光和带光斑的背景盖住（对比见 `compare-key-vs-matte.jpg`）。**只适合放在大屏里**；要直接叠在 3D 画面上的话，用 `_work/prep.py --mode matte` 重出抠图版再加深色外描边。**现在全部是草稿档（lightx2v 4 步）**，定稿档还没跑。
16 fps 原帧，不插帧；页面按歌曲时间 T 取帧（不播放视频）。口型**不对词**：唱词要对口型时用 `closeup/layers` 的 rig，和这些片段按小节交替。

用法：`createLedScreen(mv, { schedule: barSchedule(mv, { t0, pattern: ['hairflip', 'rig', 'point', …] }) })`（`mv-pdoom/kits/holo-dancer.js`）；经 `kits/stage.js` 用时写在 `createStage(mv, { led: { schedule } })` 里。

播法：loop = 首尾同一帧，可无缝循环；once = 做完动作停在最后一帧（也可以 `mode: 'pingpong'` 正放再倒放）。

文件：`<片段>/f-NNN.webp`（RGBA，848×480；`eyes-blink` 是整幅不透明、662×374；`goggles` 是竖图 832×1248）、`clips.json`（清单）、`sheet.jpg`（对比图）、`preview/<片段>.mp4`（叠底色的预览）。
生成：`_work/gen.py`（关键帧和视频的提示词、种子都在里面，`_work/calls.log` 是调用记录）→ `_work/prep.py`（抠图）→ `_work/build.py`（本清单）。`_work/keys/` 是首尾帧，`_work/gen/` 是生成的原视频。
