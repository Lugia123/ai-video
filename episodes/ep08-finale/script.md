## s01
旁白：“编译通过”，“测试全绿”，“原平台一行代码都没有”。这三句“好了”，都可能是假的。
画面：【钩子】第 0 帧：明亮纸桌面上三张纸质报告卡，一张接一张（间隔约 0.4s）盖上绿色大章：「编译通过」「测试全绿」「原平台 0 行」。「都可能是假的」时，三个绿章依次裂开，裂缝里透出红色。

## s02
旁白：报告说的，和实际发生的，中间差着一条线。前面七集，讲的都是怎么把这条线连上。
画面：画面分成两栏：左「报告说的」，右「实际发生的」，中间一大片空白。三张报告卡滑到左栏，右栏空着，中间出现一条虚线问号。说完后 1.5s 无配音系列字卡：《移植不是翻译》终章 · 报告和发生之间的连线。

## s03
旁白：说“这份代码能复用”，要连到它实际在找谁帮忙。说“这条路走得通”，要连到一段真的跑起来的试验代码。
画面：【再抓回来 ~25%】左栏卡片「能复用」→ 一条实线画到右栏 ep01 的插头与插座（代码在找谁帮忙）；接着左栏「走得通」→ 实线连到 ep02 的候选框正好落进虚线框、绿勾。每条线旁一个关键词：接缝 / spike。一次只画一条。

## s04
旁白：说“工作量大概这么多”，要连到两边都做完的同一个功能。说“原平台零行”，要连到是谁在背后替你做了。
画面：「工作量大概这么多」→ 实线连到 ep03 的两根配对柱子（同一个功能，两边都做完）；「原平台零行」→ 实线连到 ep04 的计数器「0」，背后露出一只替你干活的手。关键词：配对 / 零行。

## s05
旁白：说“编得过”，要连到它跑到了第几层。说“快捷键照搬”，要连到这个键归谁。说“测试通过”，要连到这件工具有没有红过一次。
画面：「编得过」→ 连到 ep05 的四层楼板，亮到第几层；「快捷键照搬」→ 连到 ep06 的三个圈（应用 / 终端 / 操作系统）；「测试通过」→ 连到 ep07 的仪表先红一次。关键词：分层 / 惯例 / 正对照。七条线全部连上，镜头拉远看全景。

## s06
旁白：移植难的，不是把代码翻译一遍。而是找出原平台默默替你做了什么，再确认你的工具没在骗你。
画面：【再抓回来 ~75%】七条线里有一条还是虚线；小人拿橡皮擦掉，用笔重画成实线。大字两行，一行一行出现：「找出原平台替你做的事」「确认你的尺子没在骗你」。

## s07
旁白：回到开头那三句“好了”。下次有人这么说，先问一句：连线在哪？
画面：【收尾】回到开头三张盖着裂开绿章的报告卡；小人举起一张纸条「连线在哪？」贴在上面。大字「连线在哪？」。说完画面停 ≥2.5s，然后结尾字卡 ≥2.5s，配乐收尾。
