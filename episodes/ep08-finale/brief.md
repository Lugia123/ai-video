# ep08 终章：报告和发生之间的连线

- **标题（封面大字，待用户定）**：三句“好了”，都可能是假的
  - 备选：①「有人说“好了”，先问一句：连线在哪？」 ②「编译通过、测试全绿，就真好了吗？」
- **封面画面**：三张纸质报告卡盖着绿色大章「编译通过」「测试全绿」「原平台 0 行」，绿章裂开透出红色；橙色方块小人举着黄色小纸条「连线在哪？」。视频前 3 秒兑现同一个画面（三章依次盖下 → 依次裂开）。
- **一句话目标**：看完这集，观众把前七集串成一句话：每一句「好了」，都要连到一件真的发生过的事；下次有人说好了，先问连线在哪。
- **受众**：同系列（初中生及以上；跨平台客户端开发者也能看），初一阅读水平。
- **时长估算**：约 75–80 秒（7 段，旁白约 250 字 ÷ 4.5 字/秒 ≈ 56 秒 + 停顿 + 系列字卡 1.5 + 片尾 5.6），在终章 60–90 秒目标内。横版 1920×1080 / 30fps。
- **视觉风格**：沿用系列纸质 UI + 橙色方块小人。主画面是「报告说的 | 实际发生的」两栏，中间一条条画线；每条线的右端复用对应那集的招牌画面（缩小成纸卡），一次只画一条。ep01/ep02 用成片元素；ep03–07 以各集成片为准，下表先按原稿分镜写。
- **配音**：千问 `qwen3-tts-instruct-flash` · 音色 Maia。
- **素材来源**：`source/series-script.md`（下称「原稿」）终章（:373–386）+ 系列总论点（:5–7）+ 各集一句话原则。终章原稿没有单独的「事实核对」表：它不引入新事实，只复述前七集的原则，所以下表核对的是「每条连线对应哪一集的哪条原则」。

**需要用户确认的几处**：
1. 开场 s01 把原稿「七集讲完，其实是同一件事」换成三句「好了」的钩子——原稿开场是总结句，不符合「不许用口号 / 总结开场」的规则。三句话分别取自 ep05 / ep07 / ep04 的开场钩子。「都可能是假的」是「不一定可信」的口语说法，没有声称 Polter 里这三句都真出过事。
2. s06 的总论点（原稿片头语）放在 ~75% 当「再抓回来」，不在开头说。
3. 系列标语「连线在哪？」放在最后一句当收尾，同时回扣开头三句「好了」。
4. s03–s05 每条连线复用前几集画面：ep03–07 还在写稿，若最终招牌画面和原稿分镜不同，终章画面跟着改，旁白不变。
