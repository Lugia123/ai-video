# 副歌 1（22.1–38.4 s）v4 分镜

**一句话**：她在关死的盒子里亲手把 P(DOOM) 往上调，FOOM 一声把盒子炸开，却发现整座城就是一栋满是同样盒子的楼（Chinese room）。蘑菇让城市变形，露出那张笑脸其实是 shoggoth 的面具；她拉下护目镜，用死神之眼给它标上倒计时，然后从楼顶跳下，落进跑酷那条霓虹路。

草图：`plan-sheet.png`（K1–K4，本地 imggen 改图草稿，只用来定构图和意象；正片是 3D 代码场景 + 2D 关键画）。

## 衔接
- **入**：v4-01 结尾是盒子合严、全黑，只剩四面墙上的柠黄同心圆眼睛和 ALIVE。22.06（副歌第一拍 downbeat）就从这个盒子内部开场，机位不变，四只眼还在。
- **出**：v4-03 第一帧是她背对镜头沿霓虹路跑，粉月在左上，前方是黑色圆环隧道，地面有速度线。37.3–38.4 这段要落在这个机位上。

## 母题与规则
- **P(DOOM) 翻牌全程在场且巨大**：#1 是一整面墙，#3 是楼顶的冠，#7 是 HUD 读数，#8 跟着楼倒下。数字一路上升：0.02 → 0.15 → 0.38 → 0.73 → 0.99。
- **2D 和 3D 不同屏**：只有 #6 是 2D 关键画（需要新生成：护目镜拉下 3–4 张，基于 `closeup/final/neutral.png`，用本地 imggen，不花钱）。其余全是 3D 场景。
- **多人只出现在 #3、#4**，是窗格网格阵列，所有窗里做同一个动作，不围成圈。
- **3D 动作只用舞蹈、跳跃、跑**：拉绳（#1）是唯一手部动作，拉绳本身就是一根光柱，不需要精确握持；如果试出来假，就改成双手下压一根落下来的杠杆，或者改成镜头只拍到腰部以上的剪影。
- **脚锁**：#2 的落地、#8 的落地接跑用支撑脚钉地，根位移按 v4-03 的写法。
- **只有字的镜头：0 个**。每个招牌都挂在场景里的物件上（墙顶、楼侧、蘑菇伞、面具额头、HUD）。
