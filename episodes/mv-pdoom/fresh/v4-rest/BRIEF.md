## 新增手法：唱跳表演镜头（用户 2026-10-01 定）
用户看了主歌 3 草图仍看不懂，原话：「有些实在表述不出来，要么改成主角在一个场景下唱歌，然后其他影子（特别处理一下，还是一个模型，比如变成镭射样子）在边上伴舞。这样的唱跳场景也可以在其他段落里碰到难以用情景表述的时候呈现，就像很多 MV 里，并不是所有镜头都表现剧情，也会转到歌手唱歌和跳舞镜头，来回穿插（特别是在一些副歌或者不好表现的时候）。」

所以：**歌词难以演成情节的句子，直接切「表演镜头」**，和剧情镜头来回穿插。表演镜头的规格：
- **舞台**：就在当下这个世界里（楼顶、机器里的层、回形针海……），一束主光打在她身上，霓虹线勾舞台边；不是另开一个抽象空间。
- **她**：3D 全身 / 中景跳舞，用 Mixamo 动捕（`../cast-cyber-girl/3d/anim/mixamo`，舞蹈片段多），踩拍。
- **伴舞 = 她自己的「影子」**：同一个 3D 模型的复制体，用特殊材质做成**镭射全息**样子（半透明、扫描线、彩虹镭射色散/菲涅尔边光、轻微抖动残影），站成有意义的队形（身后一排 / 两侧对称 / 镜面阵列），**动作比她晚半拍或镜像**；不叠圆圈花朵。
- **唱歌近景**：2D 关键画特写对口型（`../cast-cyber-girl/closeup/final/` 整张换图 + 按 `data/lyrics.json` 逐词换嘴型；v4-01 开头就是这么做的），或 2D 头部包转头唱。3D 的脸不拍近景。
- **歌词**：照旧霓虹招牌；表演镜头里可以挂在舞台背景上，字可以更大。
- 剧情镜头和表演镜头切换要在拍点上，每段表演至少停 2 拍，不要来回闪。

这个手法所有段都可以用（尤其副歌和难演的句子）。各段 plan 若有「怎么演都绕」的句子，改成表演镜头。镭射伴舞材质做成共用组件 `kits/holo-dancer.js`（由主歌 3 的 worker 0xe678 先做，其他段复用）。

### 表演镜头的舞台规格（用户 2026-10-01 补充，以此为准）
「一个舞台，主角在 C 位唱歌（唱歌动作），其他人伴舞；舞台一般都有屏幕，屏幕上显示大的 2D 动画——主角特写唱歌动画。」
- **舞台**：一座演唱会式舞台，放在当下的世界里（楼顶、机器层……），霓虹灯架、地面灯带、烟雾和光束。
- **C 位**：3D 的她站在舞台中央，做**唱歌动作**（握麦/抬手/身体随拍律动的唱歌姿态，不是满场跳舞；需要的话下 Mixamo 唱歌/表演类片段，如 Singing、Talking with hand gestures、Rapping 等）。
- **伴舞**：两侧/身后是她的镭射全息复制体在跳舞（kits/holo-dancer.js）。
- **背景大屏**：舞台后面是一块（或几块）巨大 LED 屏，屏上播放她的 **2D 特写唱歌动画**（2D 关键画按 lyrics.json 逐词对口型，表情随歌词变）。屏幕是舞台里本来就有的东西，所以 2D 和 3D 的她同时出现是合理的（同 v4-03 手机屏幕里的她）——这是「2D/3D 不同屏」规则的例外，仅限屏幕内画面。屏幕要有 LED 质感（像素格、扫描、轻微摩尔纹/泛光）。
- **机位**：大全景（舞台+大屏+伴舞）↔ 中景 C 位 ↔ 推近大屏上的特写（推到大屏铺满时就是 2D 唱歌特写）来回切，切在拍点上。
- 歌词招牌可以挂在舞台灯架上或做成大屏下沿字幕条。

### ⚠ 更正：剧情和舞台分开（用户 2026-10-02，以此为准，覆盖上面「舞台就在当下这个世界里」）
用户看主歌 3 舞台版分镜：「剧情和唱歌舞台没关系，不要搞混。剧情就是剧情，可以切换到剧情；唱歌舞台就是唱歌舞台。」又补充：「唱歌舞台和剧情之间不用过度衔接，但也不要太生硬。」
- **舞台是一个独立的演唱会空间**（全片同一座舞台：同样的灯架、LED 大屏、镭射伴舞），不搭在剧情场景里，也不承担剧情。
- 舞台镜头里**不演剧情**：伴舞不用队形去「演」歌词（不要「前进/后退/重复 = MLP」「全体左转对着那只眼」「升降口打开她掉下去」这种）；舞台上不放剧情道具（P(DOOM) 秤、蛇、锁、那只眼等）。舞台上就是她唱、伴舞跳、大屏放她的唱歌特写、灯光随拍；歌词可以在大屏字幕条上。
- **剧情镜头就是剧情**，和舞台镜头在拍点上**来回切**，像普通 MV 剪辑：剧情 → 切舞台唱几句 → 切回剧情，剧情从中断处继续。
- **切换方式**：不做专门的过渡衔接（不要穿越、变形、破格这种精心设计的转场），但也不要生硬——**切在强拍上**，可以配一下轻的：舞台灯光的一闪/白闪、同方向的运动（剧情里她往右跑 → 舞台镜头也往右摇）、相近的颜色或构图（剧情最后一帧的粉光 → 舞台粉色灯）。一次切换就是一个剪辑点，不额外占时间。
- 一段里哪些句子走剧情、哪些走舞台，plan 里逐句标清楚。
