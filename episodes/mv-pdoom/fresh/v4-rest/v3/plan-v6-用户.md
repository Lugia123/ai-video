## 空间：从万花筒改成「星际穿越 5D 超立方体」式的数据空间
- 参考《星际穿越》Tesseract：无穷延伸、相互垂直的三向网格，每个格子里是同一个场景在不同时刻的切片，沿三个轴向一直重复下去。纵深的线条是「时间线」被拉成的光丝。
- 我们的版本：格子里是**她自己的不同时刻**（舞台、跑酷、Sydney 手机、贴胶带的门……用已有素材做成格子里的小画面或剪影），光丝是数据流（token、0/1 沿光丝缓慢流动）。
- 色调：暖金 + 暗褐为主，点一点全片的霓虹粉青。**安静、宏大、慢**，不要满屏乱闪的彩线和字。
- FORWARD / BACKWARD / REPEAT 不用字牌，表现为光丝里的数据流**往前流 → 倒流 → 再往前**，格子里的切片跟着正放、倒放、再正放。

## 人：几乎不动，只做有动机的小动作
- 她悬浮在空间里，身体基本静止。动作只有：慢慢回头看身后 → 再转回前方。

# 结尾漫画（89.32–94.78）用户反馈（2026-10-02，看 comic/storyboard.jpg）
「睁开眼睛特写漫画不好，应该是主角缓慢睁开眼，可以有 3 镜头：一个过渡，一个是闭眼，一个缓慢睁开眼。然后主角发现是被拉住手。这里不需要机器人特写，然后歌词 go 的时候机器人放手，再跟一个主角坠落。」

新分镜：
1. 过渡：舞台灯灭 / 白光 → 漫画页（一格过渡格，不是硬切）
2. 闭眼：她的脸特写，眼睛闭着，安静
3. 缓慢睁眼：同机位，眼睛慢慢睁开（格内逐渐睁开，不是猛地睁开）
4. 发现：她抬头 / 镜头沿手臂上移，发现自己的手被一只巨大的机械手拉着，悬在夜城上空（Gato, please / don't let me 在这几格里，用她的表情和动作演：求它）
5. go：机械手松开（她的视角或中景，不做机械手的特写）
6. 坠落：她往下坠，惊恐，头发和手往上飞，夜城在下面 → 94.78 接 3D

删掉：机器人那只眼的特写（原 ③b）、DON'T/LET/ME 三连的机械手指特写。机械手只在中景、远景里作为「拉着她的东西」出现。
每格停够读（≥0.6 s，睁眼那格要慢、更久）。

## 空间第二轮（tesseract-concept2-near 用户：「空间感觉对了」）
- 晶格上整齐的像片 = 她不同时空的影像，不和当前动作对应；随机乱放的像片不要。
