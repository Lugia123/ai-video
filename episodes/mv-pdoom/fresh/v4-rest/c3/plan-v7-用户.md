# 用户看 c3-v7-half 后的修改（2026-10-02）
1. 「楼的消失很奇怪，能看到边框，是用消失显示下方回形针的方式吗？我理解的是整个楼变成回形针，然后散落下去。」→ 楼的体积本身变成回形针（楼的形状由回形针组成），然后散落、坍塌下去；不是楼淡出露出下面的回形针，不许看到楼的边框。
2. 「回形针的海洋整片是扁平的，不是实际物理碰撞堆砌出来的，有办法解决吗？」→ 用离线刚体物理模拟烘焙：近处几千枚回形针真落、真碰撞、真堆起来，把每帧的变换烘成数据，渲染时按 T 回放，保持确定性。远处用起伏的堆体（沙丘一样有高低、有阴影），不能是平面。
3. 「展示按钮的场景太单调，地面回形针是纯平面，远处高楼最好也在变成回形针掉落，还有零星从天上掉落的回形针（不要太多）让画面丰富。」
4. 「2D 漫画几个分镜里按钮表现不一样。」→ 四格按钮统一成同一个造型，和 3D 按钮也一致。
5. 「导火索不应该从按钮里面烧出来，而是从按钮底部往上冲的画面，动感和冲击感不足（包括后面衔接的 br）。」→ 拍下按钮后引线在按钮底座点着，火花从底部**往上猛冲**，要有冲击感：速度、拖尾、火星、镜头跟冲或甩、光闪、震动。一路冲进黑暗，接桥段火花继续往上冲，那一段也要同样有冲劲。

# 用户看 c3-v7-half 第二轮（物理 kit 接入后）
「开头做的还是有点敷衍，只有最近的楼变成回形针，应该是陆陆续续一直有楼变成回形针。」「人掉落中间会有回形针涌出来，这个没必要。」「人掉落高度、比例和楼不成比例，掉落没有速度感觉。」
→ ① 95.4–96.84 整个视野里的楼陆续、持续地变成回形针塌下去（远近都有，一直在发生，像波一样往外扩，不是只有她脚下几栋）。② 下落途中她周围涌出/掠过的回形针去掉。③ 她和楼的比例要对（她 1.6–1.7 m，楼几十米高），从高空往下掉要有速度感：楼从她身边往上掠过、镜头跟落、速度线/风、楼顶迎面而来，越掉越快。
