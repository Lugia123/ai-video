# 副歌 3（94.78–109.32）分镜 · v4-04c 重做

**一句话故事**：她从那只眼的爪子里掉下来，摔进一座正在被回形针淹没的城：天上不停往下倒回形针，楼顶那台巨大的 P(DOOM) 秤被压得指针越过 1.00、表盘爆成 ERR。她挣扎着游到安全室想按关机开关，按钮前的椅子是空的，负责人在休假。她爬回楼顶，四周所有 EXIT 灯一盏盏沉进回形针海，已经无路可走。秤崩开的火星点着了一条回形针串成的引信，火一路烧向地平线上的那只眼。一声闷响之后霓虹全熄，只剩冷蓝的雨。引信烧过的痕迹成了一根坐标轴，她坐在上面晃着腿，这就是正交性论题：那么聪明的东西，偏偏只想要回形针。

草图：`plan-sheet.png`（K1–K6）。K1–K5 用本地 imggen 生成，只用来定构图和意象；K6 是保留镜头的现有成片截帧。正片仍然是 3D 代码场景加 2D 关键画 / 漫画页。

## 对用户意见和总管提醒的回应
- **「除了最后坐在坐标轴上，其他都不好」**：旧版是逐句换场景的图解，每句一个不相干的画面：0.81 数字牌 → 碎片 → 回形针舞群 → 收件箱邮件 → 回形针堆里的圆圈 → 城市引信字。新版整段只有一个世界，就是被回形针淹没的夜城，每句是同一场灾难往前推一步。坐标轴镜头原样保留，而且现在有了来由：引信烧过的痕迹就是那根横轴。
- **总管提醒，她不能自己加码**：数字上涨全是外部原因。回形针从天上倒进秤盘，秤的指针被压过 1.00。她从头到尾是被动的：掉下来、被淹、找人、无路可走、看着引信烧过去。
- **P(DOOM) 母题**：载体从翻牌换成「秤式指针仪表」，和副歌 1 新方案的指针仪表是同一类东西。副歌 2 停在 1 − 10⁻³⁰（无限逼近 1），这里直接越界：1.00 → 1.07 → 1.13，指针撞断限位销，表盘裂开，读数变成 ERR，用概率超过 1 来表达「比 1 还确定」。之后每个镜头远处都还能看到这台秤，一直冒火花。
- **2D 和 3D 不同屏**：只有 #3 安全室是漫画页（2D 关键画），其余都是 3D。进入漫画页的动机是「她撞门那一瞬定格，被描成漫画第一格」（用户夸过的做法）；离开漫画页的动机是「回形针冲破格子边框，把整页埋掉，镜头从回形针堆里钻出来」。

## 母题与规则
- **P(DOOM)**：#1 是主角，楼那么高的秤式仪表，读数 1.00 → 1.07 → 1.13 → ERR；#2、#4 在远景里冒火；#5 崩开，碎片点着引信。整段没有角落小字。
- **回形针**：全段唯一的「敌人」，没有怪物，只有不停变多的回形针。#1 是雨，#2 是潮，#3 冲破漫画页，#4 是海，#5 连成引信，#7 只剩竖轴顶上那一枚。
- **那只眼**：#5 在地平线升起，确认「这一切是它干的」，接上副歌 1、主歌 3 的同一只眼。
- **歌词载体**：都挂在场景里的物件上（秤外圈、半淹的招牌、塞满回形针的窗、漫画格里的按钮和便签、EXIT 灯、秤的碎片、烧亮的引信、点阵招牌）。只有字的镜头 0 个；同一时间只亮当前这一句。
- **节奏**：每个镜头都连着上一个镜头的动作（掉 → 摔 → 滑 → 撞门 → 定格 → 破格 → 爬 → 看 → 火从脚下过 → 熄 → 坐）。没有来回闪：2D 只出现一次，进出各一次。
- **「哇」点**：#4 从特写一路升到全城被淹的航拍，#5→#6 引信烧到眼、闷响、全城熄灭变冷蓝，接保留镜头。
