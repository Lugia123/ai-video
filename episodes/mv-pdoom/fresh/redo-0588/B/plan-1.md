# 方案 B-1「镜筒」——一镜到底，往它肚子里退

总览图：`plan-1-sheet.png`（关键帧 `plan-1-kf-0a/0b/1…6.png`，草图代码在 `sketch/plan1.html`）

## 1. 一句话故事

5.88 s 镜头贴在镜片上看她的倒影——然后镜头**不出来，而是穿过玻璃往机器里面退**。一口气倒退着穿过镜头里的一片片玻璃：她先是隔着玻璃唱、笑收住；再凑上来往里瞧（一只眼被放大到铺满）；过了焦点，她的像咔一声变得锋利、并且整个上下颠倒；最后她的像落在传感器上，成了一面像素墙，被它翻正、替她摆出标准微笑，再按 Chat-G-P-T 四拍一条一条读走。

- **她遇到了什么**：她在看它，结果被它「看进去」了。
- **处境怎么变**：看的人 → 被看的人 → 一张不再听自己话的像 → 被吃掉的数据。
- **22.1 s 时她在哪**：她本人还在玻璃外面，但我们已经看不到她了；她的影像在机器里面，碎成像素顺着镜头方向流走，直接汇进副歌第一拍的画面。

为什么不是「一词一图」：全段只有一个动作（镜头沿光轴后退）和一件事（她的像被吞进去）。虚焦→合焦、正像→倒像、光学像→像素，都是真实镜头里沿着这条路必然依次发生的事，不是为某个单词摆的道具。

## 3. 歌词呈现方案

**歌词 = 镜头上的刻字。** 真实镜头的压圈上本来就刻着一圈字（焦距、光圈、序列号），这里刻的是歌词。

- 字体：Bebas Neue 全大写。没唱到的词是金属上的暗刻痕（看得见但不抢）；唱到的词填上柠黄漆并发光；唱过的保持柠黄不发光。
- 位置：每片玻璃的压圈上弧（长句再用下弧）。主体永远在玻璃圆的正中，字永远在圆外的环上，**物理上不可能压到她**。
- 尺寸：草图里字高 74 px（画高 6.9%）；丝印行 110–116 px。
- 出入：字随压圈一起从画面外退进来、再随镜头后退缩小退场，不做独立的飞入飞出。每句在自己的环上从第一个词亮起到整环退出画面 ≥ 2 秒；DROP / BOSS / EAT 三个词各自加一次脉冲。
- 传感器之后没有压圈了，换成电路板上的**白色丝印**（同字体同色），在像素墙下方的空板面上，一行。
- **0–5.88 保留段怎么补**（画面不动，只加字）：
  - 1.4–3.7 鱼眼 POV：鱼眼圆外两侧的暗处就是遮光罩内壁，I / SEE 刻在左侧一摞，SPARKS / OF 刻在右侧一摞，字高 120 px（kf-0a）。
  - 3.7–5.88 墙上那只眼：银灰压圈正好有 80 px 宽——A·G·I 三个字母刻在压圈上弧，跟现有三圈光环同拍亮；IN YOUR EYES 刻在下弧，随镜头推近一起放大（kf-0b）。
  - 这样保留段和重做段是同一套字、同一种载体，5.88 s 处不换风格。

## 4. 「哇」点

**10.66 s，DROP。** 之前 4.8 秒画面越来越暗、越来越糊（退进镜筒深处 + 失焦），在 DROP 这个词上 3 帧之内同时发生三件事：画面一沉、从一团光斑变成全片最锐利的一张脸、整个世界上下颠倒。这是全段反差最大的一下，也是她处境翻转的那一下。

第二个小高点在 15.66 s（BOSS）：像素墙上的她自己笑了、眨眼了——画面最「乖」的一刻其实最不对劲。

## 5. 素材 / 新关键画清单

**零新图也能做**，全部用现成素材：

- 2D 正脸关键画（`cast-cyber-girl/closeup/final/`）：neutral、smile、wink、surprised、eyes-half、eyes-closed、mouth-a/e/i/o/u——口型对词、表情切换、像素墙采样源。
- 2D 头部包（`kits/face2d`）：第一句里往左右瞟的小角度转头。
- 其余全部代码生成：镜筒、玻璃折射 / 色散、光圈叶片、六边形光斑、像素墙、丝印电路板。不用 3D 女主（所以不存在 2D 和 3D 同屏）。

## 风险和没验证的地方

- 草图是 2D 画布拼的示意，**玻璃折射、色散、合焦那一下的手感都还没做**，成片效果取决于这几个着色器，尤其是 10.66 s 那 3 帧。
- 她全程是 2D 立绘 + 口型，肢体动作只有凑近 / 后缩 / 转头 / 眨眼；如果用户想看她「全身做事」，这套给不了，看 B-2。
- 上下颠倒的脸唱歌约 2 秒（10.9–12.75），口型可读性会下降，这是故意的不适感，但用户可能不喜欢。
- 我没读旧分镜（按规定），只凭 BRIEF 里列的旧做法和 `kits/` 的导出名避让；镜筒 / 光学元件 / 像素墙在 kit 里没有对应物，光圈在旧版被用作「嘴」，这里只是路过的一个框，不张合。
