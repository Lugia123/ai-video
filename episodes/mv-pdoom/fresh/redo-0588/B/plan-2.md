# 方案 B-2「合拢」——空间折叠，她站在一只摊开的盒子里

总览图：`plan-2-sheet.png`（关键帧 `plan-2-kf-0a/0b/1…6.png`，草图代码在 `sketch/plan2.html`；草图里的人是积木替身，成片换 3D 女主 + 动捕）

## 1. 一句话故事

镜头从镜片里退出来，她想离那只眼远一点——可走廊在缩短，退到另一头，身后墙上也有一只。然后四面墙轰地向外倒平，镜头一口气拉到高空：她原来站在一只**摊开的纸盒**正中，四面墙上各一只眼，脚下的虚空里是一望无际、已经合上的盒子。接着四面墙按 Chat-G-P-T 四个音节一面一面合上，盖子压下来，22.1 s 合严。

- **她遇到了什么**：她以为自己在一条走廊里看一只眼，其实她在一只还没合上的盒子里。
- **处境怎么变**：平视它 → 想躲开 → 发现四面都是它 → 被围住、跪下 → 被关进去。
- **22.1 s 时她在哪**：在合严的盒子里。全黑，只剩四面墙上的眼睛亮着。副歌第一拍从这片黑里炸开。

为什么不是「一词一图」：全段只有一个物体（这只盒子）做一个完整的动作（缩 → 摊开 → 合上），她的每个动作都是对盒子上一步的反应。

## 3. 歌词呈现方案

**歌词 = 刷在板子上的喷漆字**（舱壁 stencil，像飞船舱壁上的 CAUTION）。这个世界里只有白板子，字就刷在板子上，板子动字跟着动。

- 字体：Bebas Neue 全大写，粉 #FF2E88。没唱到的词是很淡的底漆印；唱到的词变实并亮一下；唱过的保持实色。盒子合上之后，同样的粉字变成自发光。
- 位置规则：永远刷在**她没站的那块空板面**上——侧视时在她头顶上方的墙沿；俯视时在她南北两侧；仰拍时在正面墙那只眼的上方；最后在盖子内面。
- 尺寸：按字高 ≥ 画高 5%（54 px）设计。草图里 kf-1/2/3/5/6 达标；**kf-4 的字在草图里偏小（约 45 px），成片要把机位再往前推约 0.8 米或把那一屏拆成更短的两行**，这个我在草图里没调到位。
- 出入：不飞入飞出。同一块板上换句时，旧字像被擦掉一样从左到右淡成底漆印，新字逐词亮。SERVANT、BOSS 各停留 ≥ 1.4 秒；DROP 那两行停留 2 秒以上。
- **0–5.88 保留段怎么补**（画面不动，只加字）：
  - 1.4–3.7 鱼眼 POV：鱼眼圆外两侧暗处，粉色喷漆字，左 I / SEE、右 SPARKS / OF，字高 130 px（kf-0a）。
  - 3.7–5.88 墙上那只眼：眼睛两侧的空墙面，左边 A / G / I 竖排、三拍各亮一个，右边 IN / YOUR / EYES（kf-0b）。镜头推近时两侧的字自然滑出画面，5.88 s 时画面里只剩倒影。

## 4. 「哇」点

**10.66 s，DROP。** 前 4.8 秒观众一直以为这是条走廊、是间屋子；DROP 这个词上四面墙同时倒下，镜头 0.4 秒拉到高空，尺度一下放大几十倍——她只是十字正中的一个点，而且脚下还有无数只一模一样、已经合上的盒子。这一下同时交代了「这是只盒子」和「别人都已经在里面了」。

第二个高点是 16.6–18.4 的四声「砰」：ChatGPT 这个词本来就拖了 2.5 秒、正好四个音节，一个音节合一面墙。

## 风险和没验证的地方

- 草图是白模 + 积木人，**没有阴影、没有真正的 3D 女主、没跑动捕**。「光一块块少」和最后那道天光在成片里靠阴影和体积光，草图里只是示意，这部分手感没验证。
- 她全程是远景小人，**没有脸部表演和口型**。第一句被认可的恰恰是脸；如果用户要的是延续那张脸，这套不如 B-1。
- 5.88–7.72 只有 1.84 秒，要完成「镜头从镜片退到侧面 + 她倒退 + 墙压过来」三件事，偏挤；可能要把墙开始滑动提前到 5.5 s（落在保留段末尾，需要用户同意动那半秒）或者砍掉墙滑动、只留她倒退。
- 走廊「缩短」是个作弊：保留段里那是一条很长的走廊，这里要在 3.6 秒内缩成 3 米见方的盒子。侧视角下应该读得通，但没做动态验证。
- 我没读旧分镜（按规定），只凭 BRIEF 列的旧做法和 `kits/` 的导出名避让。`kits/world4.js` 里有 `createMirrorRoom`、`kits/transit.js` 里有 `unfold`，说明「房间」和「展开」在别的段落可能出现过；本方案的六块板和铰链是自己建的，不复用它们，但如果旧版某处已经有过「盒子摊开」，请总管帮我对一下。
