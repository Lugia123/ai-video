# 方案 1「抽考」：师生互换

草图：`plan-1-sheet.png`（单张 `plan-1-kf-1…4.png`）

## 1. 一句话

她是老师，拿题卡考一只坐在矮课桌后、又小又暗、答什么错什么的「眼」；drop 那一拍题卡像下雨一样掉下来，它一口气全答对，顺着支柱长得比她高，反过来出了一道她看不懂的题——✗ 落到了她头上。
观众读懂的是：**刚才是她考它，现在是它考她，她答不上来。**

核心比喻：谁出题、谁被打叉。画面里没有曲线、没有读数，「开窍」是用「题卡全对 + 它长高 + 出题权换手」三件事演的。

## 3. 怎么进、怎么出

- **进**：9.52 硬切。前一帧是她一只眼的超近特写，这一帧她的脸在画面左侧，眼睛位置大致对上（特写的那只眼落在她右眼的位置），所以切过去视线不跳。
- **出**：12.75 起它身后的像素肖像推满画面，就是现在 13.16 的像素墙，**只是这次她是正的**（颠倒已经去掉）。13.16 之后的读出线、方块掉落、盒子全部不用改。像素墙在这里有了来由：它「学会」的那样东西就是她。

## 4. 素材 / 新关键画

- 2D 关键画全用现成的：`eyes-half`、`eyes-closed`、`surprised`、`mouth-i`、`neutral`。**新关键画 0 张。**
- 眼、支柱、课桌、题卡、✓✗、超立方体：代码画（眼沿用现有的眼）。
- 她没有手出镜：题卡是挂着的小招牌，自己翻面。如果想要她「举着」题卡，需要 1 张千问（她单手举一块方牌到脸侧）；我认为不必要。

3. 11.7 s：位置互换，它出题。
4. 12.3 s：✗ 落在她头上，像素肖像滑入。

## 风险

- 3.6 秒里有六个节拍，偏满。最容易砍的是 9.80 的叹气和 11.34 的抬眼；砍掉后剩「答错 → 全对长高 → 它出题 → 她被打叉」四步。
- ✓ 和 ✗ 是符号。它们在这里是「阅卷」这件事本身，不是往画面上贴标签，但如果用户对任何符号都反感，这套就不合适。
- 她全程只有脸在演，没有肢体。
