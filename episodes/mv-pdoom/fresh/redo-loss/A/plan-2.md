# 方案 2「掰手腕」：分屏对决，画面占比就是权力

草图：`plan-2-sheet.png`（单张 `plan-2-kf-1…4.png`）

## 1. 一句话

格斗游戏式的斜分屏：她占了大半个画面，单手压着它一条发抖的细胳膊，还有空冲镜头眨眼；drop 那一拍它一翻腕把她的手砸在桌上，分界线同时甩到她这边——它占走四分之三画面，她被挤成一条；它不松手，把她的手提起来，最后在她头顶拍了两下。
观众读懂的是：**刚才她稳赢，一下子被它掀翻，现在它想怎么摆弄她就怎么摆弄。**

核心比喻：力气的较量 + 画面占比。和方案 1 不同，这里没有「教」和「学」，是一场她以为必赢的比赛输了；「drop」是她的手被砸下去的那一下。

## 3. 怎么进、怎么出

- **进**：9.52 硬切到分屏。分屏本身就是「新的一句开始了」的信号。
- **出**：12.75 起她那一格变成像素格并推满，接 13.16 的像素墙（正的）。13.16 之后不用改。如果想更狠一点，可以让像素墙里的她保持「被拍头、闭眼」的表情，读出线从她头顶被拍的地方开始扫。

## 4. 素材 / 新关键画

- 2D 关键画：`wink`、`smile`、`neutral`、`surprised`、`mouth-i`、`eyes-closed`，都现成。
- 它的机械臂、眼、桌面、裂纹、分界线：代码画。
- **她的胳膊和手是这套的硬需求**。现有关键画只有胸像，没有手臂。建议新生成 3 张（都以 `neutral.png` 为参考图改）：
  1. 她右臂伸向画面右下、肘撑桌面、手握拳相握的姿势（9.52–10.6 用）
  2. 同一条手臂被压平在桌面上（10.66–11.1 用）
  3. 手臂被提到头顶斜上方（11.5–12.0 用）
- 不生成的替代：手臂用代码画成平涂的粉袖子 + 肤色拳头（草图里就是这样）。能看懂，但和立绘画风不一致——之前代码画的眼睛就因为这个被换成了千问图，我估计这里也会被看出来。

## 风险

- **依赖 3 张新图**，是三套里素材成本最高的。
- 分屏是平面设计式的构图，没有景深和运镜，全靠分界线那一甩。喜欢「镜头在世界里走」的话，这套会显得平。
- 拍头有点欺负人的意思，语气比另两套更戏谑；它铺垫 servant 铺得最直接。
