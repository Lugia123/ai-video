# 方案 3「拖 → 拎」：谁拽着谁

草图：`plan-3-sheet.png`（单张 `plan-3-kf-1…4.png`）

## 1. 一句话

夜里的霓虹公路上，她把绳子扛在肩上，死命拖着一只又大又暗、在地上磕磕绊绊的「眼」往前走；sudden 那拍绳子突然不沉了，drop 那拍它直冲上天，绳子绷直，把她一把拎离地面——整座城市从她脚下掉下去；镜头拉开，它已经胀得盖住了月亮，她是绳子末端吊着的一个小点。
观众读懂的是：**刚才是她费劲带着它走，现在是它拎着她，而且它大得吓人。**

核心比喻：一根绳子两头，谁拽谁。和前两套不同，这是 3D 全身的大远景动作戏，没有脸的特写，也没有符号；「drop」是地面掉下去（对她来说是脚下一空）。

## 3. 怎么进、怎么出

- **进**：9.52 硬切，用「环对环」的匹配剪辑——前一帧是她瞳孔里的柠黄光环，这一帧同一位置是地上那只暗眼的镜片环，然后 0.3 s 内拉开成公路全景。
- **出：这一套要改 13.16–15.5，这是它的代价，也是它的好处。**
  - 现在的 13.16–15.5 是「像素墙被读出线扫成方块 → 方块掉进盒子 → 聚成 3D 的她」。这一套里她已经是 3D 的、已经在城市上空，像素墙没有来由了。
  - 建议改成：13.16–14.6（now I'm your servant）它拎着她飞到盒子正上方，像抓娃娃机的爪子吊着奖品；14.6 松绳，她掉进盒子（动捕 `move__fall-air` → `move__hard-landing`），落地蹲姿——**正好接上现在 15.5 那一帧她蹲在盒子正中的画面**，15.66 四只眼睁开、之后关盒子全部不变。
  - 不想改那么多的话有折中：她吊在半空时，它的读出线从她脚往上扫，把她扫成方块掉下去，14.6 之后的方块落盒照旧。只换掉像素墙那 1.4 秒。我觉得不如直接掉下去干净。
  - 工作量：0xb52e 那边 13.16–15.5 的镜头要重做，招牌 `NOW I'M YOUR SERVANT` 的位置要重排。

## 4. 素材 / 新关键画

- **新关键画 0 张**，这一套没有 2D 的她。
- 3D 女主 + 现成动捕：`act__pull-rope`、`act__float-flail`、`move__hang-sway`、`move__fall-air`、`move__hard-landing`，`index.json` 里都标了可用。趔趄那两步没有专门的片段，打算用 `move__land-run` 的前半段，**要先试**。
- 城市、公路、月亮、盒子：沿用跑酷段和关盒子段的场景。眼沿用现有的。绳子是新写的（一条两端固定的悬链线，松 → 直）。
- 手和绳子的贴合：远景里手握绳子的位置只要大致对上；10.66–11.1 那段中景她是正面全身，手得真的抓在绳子上，需要给手腕加一个朝绳子的约束。

## 风险

- **看不到她的脸**，慌是靠乱蹬的手脚和尺度演的。
- 要动 13.16–15.5 的已完成镜头（见第 3 节）。
- 10.66–11.1 那段正面中景是 3D 的她离镜头最近的时候（全身约占画高四成，脸约 7%，在契约的 30% 上限以内）。风险不在清晰度，在表演：乱蹬是现成动捕，和绳子的受力未必对得上，看着假的话就改成背后视角或更远的景别。
- 「拎着她往盒子去」会让人想到抓娃娃机，偏喜剧；和后面关盒子的压迫感之间有一点语气落差。
