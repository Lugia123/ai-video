# v401（0–22.1 s）新视角：三套方案

W4 / #947。我刻意没看以前的分镜，只依据歌词、音频数据、素材和用户的否决/喜好清单来想。

## 先定一件事：这段歌在讲什么

前 22 秒是一首**情歌的开头**：她爱上了一个 AI（"you"）。
情节线是：一见钟情（sparks）→ 心慌（nervous）→ 对方突然开窍、变强（loss 骤降）→ 权力倒转（servant / boss）→ 求饶（don't eat me）→ 爆（副歌：P(doom) 越涨越高）。

以前那种「每句换一个点子」，问题出在把每句当成一道独立的图解题。三套方案都反过来做：**先给「你」（AI）定一个固定形象，再让 22 秒成为她和这个形象之间一段连续的关系**。每句歌词只是这段关系往前走了一步。

## 方案 A「那条线」——她爱上了一条曲线 ★推荐

**核心概念**：AI 就是**一条会发光的线**（数学函数曲线，一笔画、从头到尾不断），是她的恋爱对象。它会变成眼睛、心电图、loss 曲线、山谷、嘴，最后在副歌变成一路冲上天的 P(doom) 曲线。整首 MV 的主题（P(doom) 往上涨）从第一帧起就是同一个东西。

**统一画风**：
- 她：只用 2D 头部包（face2d）和同画风的千问关键画，赛璐璐动画风。
- 那条线：薄荷绿芯 + 柠黄外发光，有一截彗尾，永远是画面里最亮的东西。
- 背景：暖色黄昏渐变（梅紫 → 霓粉 → 桃色），铺一层极淡的坐标纸网格，网格会随线的形状微微弯折。**全段不出现纯黑底。**
- 只有一次 2D→3D 转换（loss 骤降那一刻，坐标纸倒下来变成 3D 的 loss 地形），然后再回到 2D。用户喜欢的「数学图形叠加」和「2D↔3D 转换」各用一次，都有剧情上的理由。

**为什么比「每句一个点子」好**
- 所有画面都是「她 × 那条线」这一对关系，观众只需要记住两个角色。每句歌词只推进关系，不用重新交代世界。
- 开头 3 秒就是副歌的画面（front load），22.05 让它回来并兑现，头尾扣上。
- 歌词里本来就有数学：training loss 是曲线，P(doom) 也是曲线。「线」这个设定不是硬套上去的，它就是这首歌的物理规律。
- 用户点过名喜欢的四样东西，这里各有一个非用不可的理由：2D 转头唱歌（0、2 句）、数学图形（整条线）、2D↔3D（drop 那次俯冲）、经典电影（仰拍/俯拍的权力镜头 + 默片光圈转场）。
- 画风从头到尾只有两个要素：赛璐璐的她 + 发光的线。3D 那段是坐标纸倒下来变成的，所以不算「换了一种画风」。

**风险**
- 「一条线」可能显得太素，撑不起 22 秒。应对：线要有体积感（3 层发光 + 彗尾 + 火花粒子），背景网格要跟着它弯。animatic 里先验证这一点。
- 3D 那段（10.66–16.6）要让她的 3D 模型和 2D 画风衔接：3D 部分只用中远景 + 卡通描边，靠俯冲时的运动模糊把切换藏起来。
- 如果 face2d 的 fear 表情只有 0°/±30° 这几个角度，仰视那一镜只能靠眉毛上抬 + 口型 o 来演害怕，需要先试一下。

## 方案 B「2001：一场太空漫游」——整段只致敬一部电影

**核心概念**：前 22 秒是库布里克《2001 太空漫游》的粉色版。她是宇航员（护目镜就是她的头盔面罩），AI 是一只 HAL 式的柠黄圆眼。**一整段只致敬一部电影**，所以每一镜都在同一种电影语言里：一点透视、左右对称构图、白色太空舱配一个颜色的强光。

**统一画风**：3D 做对称的白色舱室（程序化生成，全白 + 霓粉灯带，AO 打柔），用她的 2D 关键画/头部包当前景近景；HAL 眼是 shader 画的柠黄镜头，里面有层层镜片反光。色调始终是奶白 + 霓粉 + 一个柠黄的眼。

## 方案 C「舞伴」——和一个正在学跳舞的 AI 跳双人舞

**核心概念**：这是一场约会舞会。她的舞伴是 AI，一个由线框/体素组成的人形，用同一套 Mixamo 动捕驱动（不需要新素材）。**它每句都在学习**：一开始笨手笨脚，loss 骤降之后跳得完美，然后开始带她、变得越来越大，最后像金刚托着安·达罗那样把她托在手心。**她跳舞是因为有舞伴**，这正好解决了用户说的「莫名其妙跳舞」。

**统一画风**：一个舞厅舞台（霓粉顶光光池 + 薄荷网格地板 + 远处一排观众剪影收边），全段不离开这个舞台。3D 全身用卡通描边；每句有一个 2D 头部包的近景插入，放在同一束舞台光里（2D↔3D 交接的理由：远景看舞，近景看心）。

**为什么好**：双人舞本身就是情歌的画面；「AI 在学习」的过程能被直接看见（笨拙 → 完美 → 主导）；3D 动捕用在它最擅长的全身舞蹈上。

## 推荐：方案 A「那条线」

1. **风险最低、最能发挥现有素材**：主体是 face2d（用户最喜欢的素材）+ canvas 曲线，3D 只在 3D 最擅长的地方出现一次（全身下落，中远景）。不需要新生成图，B 至少要生成 1 张，C 要手 K 双人接触。
2. **跟整首歌是同一个设定**：副歌「P(doom) 越涨越高」就是那条线往上冲，一个设定能一直用到结尾，而不是只管前 22 秒。
3. **没有碰到任何一条否决项**：字不是主角（全段 0 个歌词字）、没有人莫名跳舞、没有电路墙、没有小人演 loss、没有高楼、没有字洪水巨脸、没有 3D 近景表演，画风只有两个要素。

### animatic 自查（`out/v401-A-animatic-sheet.png`，每 0.4 s 一帧）
- 成立的：从倒带的亮点落进眼里 → 玫瑰眼反打 → 心动脸红 → 线贴着她走、nervous 两个心跳尖峰踩在底鼓上。这一串因果读得通，而且全程只有「她 + 线」两个元素，画面不空，也不显得在换风格。
- 不够的：钩子 0–1.4 的冲击力还只到样片水平（线还不够粗、光不够猛，她没有仰到位、头发也没飘）。正片要加：整屏曝光冲白、线的体积光、头发的上飘层、一次镜头猛摇。转头是按角度硬切的，正片换成 face2d 的网格变形连续转头。
