## 她怎么放进这个世界（不假、不混风格）

1. **脸只用整张关键画**（closeup/final 的 neutral / smile / surprised / eyes-closed / mouth-a/e/i/o/u）。口型、眨眼 = **整张换图**（lyrics.json 逐词时间 → 元音表），不用 face2d 分层叠画 → 从结构上就不可能出现眼 / 嘴贴图错位。白底在载入时从图的四边泛洪抠掉（眼白、高光在内部不受影响），边缘羽化 1 px。
2. **2D 画面只以「这个世界里本来就有的影像」出现**：
   - **HAL 的监控画面**：她是一张纸片，真的站在 3D 长廊里（离镜头 0.8–1.35 m），身后是亮着粉灯的舱室，边缘有粉色背光溢边；然后整幅画面（她 + 舱室）一起过鱼眼畸变 + 圆形暗角 + 边缘色散。观众读到的是「HAL 的摄像头拍到的她」，2D 和 3D 被同一个镜头统一，而不是 2D 贴在 3D 前面。
   - **镜片倒影**：她的画被凸面镜片反射（球面压缩、左右镜像、暗玻璃、粉色染色、镜片高光压在上面、柠黄芯从她身后透出来）。脸的特写因此是「在眼睛里看到她」，同时也是情歌的画面（她映在「你」的眼里）。
3. **3D 的她只出现在大全景**：背影、离镜头 6.7 m、占画高约 30%，不给脸；和 2D 近景之间的桥梁是同一个舱室、同一种粉光。
4. 全段只有一种电影语言：一点透视、对称、白 + 霓粉 + 一只柠黄眼；没有漫画字效、没有网格、没有别的风格元素。只借构图 / 调度（对称长廊、鱼眼 POV、眼睛特写），不复制原片画面，眼睛的造型是自己画的（金属外圈 + 三层镜片环 + 柠黄芯）。

## 做成整段（0–22.1 s）还缺什么

- **后半段的调度**（按 v401-ideas.md 方案 B 表）：loss 骤降那一跳切（她抛出的曲线 → 沿曲线急降的飞船，需要程序化飞船 + 太空背景）、舱门外敲门（门 + 门上的眼）、Chat-G-P-T 四拍瞳孔光圈叶片张开成「嘴」、被吸进瞳孔 → 星门隧道（slit-scan 着色器）接副歌。舱室 / 眼睛 / 鱼眼 / 倒影这四块积木都可以直接复用。
- **开头的星门闪前**：方案里「护目镜拉下来」那张图我没做（不新生成图）；样片改成「舱室通电」开场。若要星门钩子，可以先用现有关键画 + 护目镜镜片里倒映光墙（和本样片的倒影做法同一招）来替代新图。
- **表情覆盖面**：整张关键画只有 11 张正脸（无侧脸 / 仰视）。「读唇」侧面、「害怕仰视」这类镜头要么用 face2d 的 yaw 组（必须逐帧查错位），要么补生成同画风整张图。本样片只用了正脸，所以都放在「对着 HAL 镜头」的机位里——正好合理：她总是看着 AI。
- **口型精度**：现在是按词一个元音；整段要更细的话按音节拆（AGI 已拆成三拍）。
- **舱室质感**：现在是 Lambert + 点光，墙面偏灰粉；终版可以加 AO（烘一张渐变贴图）、地面反射、灯板更亮的白、更干净的「2001 白」。
- **3D 背影的动作**：现在是 idle 呼吸 + 往后半步；全段还要走进长廊（walk）、敲门、仰头等，都只拍背影 / 远景。
- 渲染：GPU 约 130 ms/帧；鱼眼镜多一次 RT。
