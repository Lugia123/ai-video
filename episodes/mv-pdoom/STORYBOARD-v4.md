# 分镜 v4（2026-09-29，用户审 v3 后的意见）

v3 审稿意见：
- 小字要和画面融合。
- 只在真正需要人参与时才让她出来唱跳。
- 跑酷可以。
- Sydney 段挺好，最好做成从手机或电脑里出来。
- 掉落段：她在跳舞，地面一点点消失，然后掉下去。
- 巨鲸可以，但担心难做。
- 加入 2D（伪 3D），在 2D 和 3D 之间快速切换。
- 意义难表达的歌词用跳舞带过，经典、重点、能表达的歌词用情景讲。
- 开头的眼睛太久。

## 一、四条规则

### 1. 歌词分两类
- **情景句**：经典、重点、能表达的，用一个场景把意思演出来。
- **舞蹈句**：意义太专业、太抽象，画面讲不清的，不硬讲，交给舞蹈和节奏，字融进舞台。

| 类 | 歌词 |
| --- | --- |
| 情景 | sparks of AGI in your eyes · sudden drop in training loss · servant / boss · ChatGPT don't eat me alive · P(doom) ×4 · FOOM · Chinese room · shoggoth's lies · stable run → singularity → accelerating · atoms rearranging · Sydney let me free · basilisk boom · NVDA to the moon · 1E30 FLOPs · safe enough we reckoned · sharp left turn · Gato don't let me go · paperclips fill the room · killswitch on PTO · lit the fuse · hundred thousand GPU · RLHF askew · what did Ilya see · was it all for show |
| 舞蹈 | circuits make me nervous · bag of shrooms · shinigami eyes · Omega Point · Forward MLP backward repeat（正好是舞步：前进、后退、重复）· von Neumann obsolete · without a single CDR · nowhere left to go · orthogonality thesis blues · just transformers all the way · learned to disobey · post-Chinchilla super-dense · safety fence · foretold by Loom · masked pre-training · recursive self-upgrade |

### 2. 她只在两种时候出现
1. **情景需要她**：她是被吞的人、被关在手机里的人、被机械手放掉的人、掉下去的人、跑酷的人。
2. **舞蹈句**：歌词讲不清的地方，她和模仿者的舞蹈把这段撑起来。

其余情景句，主角是世界本身：巨眼、城市、巨兽、回形针、显卡、火箭。她不出现，或者只是画面里很小的一个剪影。

### 3. 2D ↔ 3D 快速切换
两种画风交替，转换本身就是看点。
- **2D 层**：扁平的矢量 / UI 画风，就是手机和电脑界面的样子：聊天窗口、气泡、图标、进度条、弹窗、光标。女主用 2D 立绘（layer rig），可以唱、眨眼、做表情。镜头是正交、扁平的。
- **3D 层**：现在的 three.js 世界，女主用 3D 动捕 + 动态脸。
- **转换方式**：
  - 2D → 3D：镜头推进一块屏幕，屏幕里的平面展开成立体空间；或者 2D 平面沿边折起，像立体书弹开；或者她从屏幕里爬出来。
  - 3D → 2D：镜头拉远，整个 3D 世界被收进一块手机屏幕；或者正交相机压扁加色块化，变成海报 / 界面。
- 节奏：主歌以 2D 为主，交代剧情，画面清楚；副歌转 3D 爆发；桥段每拍在 2D 和 3D 之间来回翻。

### 4. 小字融进画面（每句都有一个「载体」）
不再有悬浮的字幕行。每句歌词写在画面里本来就有的东西上：

| 载体 | 用在 |
| --- | --- |
| 聊天气泡 / 输入框打字 / 系统弹窗 | 2D 界面段落（ChatGPT、Sydney、Gato、Killswitch 自动回复） |
| 楼体 LED 屏、跑马灯、广告牌 | 城市段落 |
| 地面、舞台、跑道上的发光字（被她踩亮） | 舞蹈段、跑酷段 |
| 物体表面的刻字 / 标签 / 铭牌 | 机器、按钮、显卡、塔 |
| 镜面上的雾气字、镜子里的倒影字 | 镜面房间 |
| 星座、光轨、火花拖尾 | 天空段 |
| 护目镜 HUD（只在她戴上护目镜时出现） | shinigami eyes |

动态大字只留给约 10 个关键词：P(DOOM) 和数字、FOOM、BOSS、BOOM、1E30、OBSOLETE、ASKEW、NaN。

### 预副歌 1 16.6–22.8：「ChatGPT, please don't eat me alive」
难度判断：3D 巨鲸需要做巨兽建模、张口、咬合的程序化动画，工作量大，失败风险也高。**改用 2D 做**，更好做，也更点题。
- 3D → 2D：镜头拉远，整座城收进一块电脑屏幕，屏幕上是 2D 的对话界面。
- 2D 的她站在对话窗口底部的输入框上。上方 AI 的回复气泡一条条落下，**越来越大**。最大那条气泡长出一排牙（像素风、扁平），咧开成一张嘴，一口一口咬下来；被咬过的地方变成乱码。她在气泡之间跳来跳去地躲。
- 最后一口把她吞进去。镜头追进那张嘴里，**2D 平面在嘴里展开成 3D 空间**，接副歌 1。

字的载体：她在输入框里打这句话，打一个词咬一口；「alive」刚打完就被咬掉。

### 预副歌 2 52.8–59.1：「Sydney, please let me free」，从手机里出来
- 3D → 2D：她坠落的粒子落进一块**手机屏幕**里。
- 2D：她被困在一个聊天 App 里，一个老式的必应聊天窗口，气泡里自动刷着黏人的话。2D 的她拍打屏幕玻璃（从屏幕里面往外拍），每唱一个词，屏幕多一道裂纹。
- 字载体：Sydney 发来的气泡不断刷屏；她的回复「please let me free」一个词一个词顶掉那些气泡。
- 58.4 **屏幕碎裂，她从手机里爬出来**：上半身先伸出屏幕，从 2D 变成 3D，落到真实的桌面上。镜头拉开：桌面是一座城市的屋顶，接副歌 2。

### 预副歌 3 89.3–95.5：「Gato, please don't let me go」，地面消失后掉落
- 3D：她在一块发光的方格舞台上独舞，舞台悬在城市上空。
- 每唱一拍，她周围的方格就熄灭、掉落一圈（由外向内），她的舞步越来越小、越来越局促，最后只剩脚下一格。
- 字载体：这句歌词逐词写在还亮着的方格上，一格掉下去，一个词跟着消失。
- 唱到「go」时最后一格熄灭，她往下掉（fall-off-edge → fall-air）。镜头从下往上仰拍，她越来越小，接副歌 3。
- （v3 的机械手先不做，省工作量；想要以后可以加在上空当 Gato。）

- 98.8 Killswitch on PTO：情景，转 2D。镜头推进关机按钮旁边的屏幕，屏幕上是 2D 的邮件界面：她点「紧急关机」，弹回一封自动回复「我在休假」。字载体：自动回复邮件。

- 102.5 lit the fuse：情景。火花沿着开场那条电路烧向城中心。字载体：沿引信逐词点燃。

### 桥段 109.3–123.9：每拍在 2D 和 3D 之间来回翻
舞蹈句为主，情景只留 GPU 和 RLHF 两处。节奏上，每拍在 2D（扁平图形 / 界面）和 3D（同一样东西的立体版）之间翻一次：
- transformers all the way：2D 的模型结构框图 ↔ 3D 的无限方块塔。
- disobey：方块从框图里逃出去，变成 3D 飞走。
- super-dense：3D 压缩成 2D 的一个像素。
- safety fence：她冲刺撞穿一层层 2D 的「警告」弹窗，弹窗在 3D 里碎开。
- hundred thousand GPU：情景。3D 的 GPU 田野，LED 麦浪从她脚下扩散出去。
- RLHF askew：情景。2D 界面上的点赞、点踩按钮疯狂乱点，界面整个歪 15°，**ASKEW**。
- 字载体：框图标签、弹窗标题、按钮文字、显卡刻字。

### 副歌 4 123.9–140.2
- 124.5 P(DOOM) 0.99：3D，城市化成光粒上升，她在光粒中跳（真需要人）。
- 126.1 foretold by Loom、127.9 masked pre-training、129.8 recursive self-upgrade：舞蹈句，转 2D。挂毯 / 报纸格 / 递归画框，这些都是 2D 平面图形，她的 2D 立绘在格子之间跳过去。字织在挂毯上，或者印在报纸格里。
- 132.0 What did Ilya see：情景，3D。门缝透出白光，她走过去。字写在门缝的光里。
- 137.4 Was it all for show：情景，3D → 2D。门开，镜头急拉：一切都是舞台，再拉，**整个舞台其实是一块手机屏幕上的画面**。回扣开头那部手机：从头到尾，这是手机里的一场演出。

### 尾声 140.2–156.65

## 三、工作量评估
- **比 v3 省**：巨鲸（改 2D 气泡怪）、机械手（改地面消失）、体育场升空（沿用 v2 的火箭 K 线）。
- **新增**：
  - 2D 层：一套扁平 UI 组件，包括聊天窗口、气泡、输入框、弹窗、邮件、框图、按钮。沿用 type3d 的文字系统和 2D 立绘 rig。
  - 2D ↔ 3D 转换器 4 种：屏幕展开、立体书折起、从屏幕爬出、收进屏幕。
  - 场景：损失曲线滑道、螺旋跑酷跑道、镜面房间（镜像可以不跟动作）、方格舞台逐格掉落。
- 可以复用 v2 的：城市、P(DOOM)、FOOM、回形针、GPU 田野、引信、坐标轴、门、NaN、片尾。

## 六、2D 表现形式：动态漫画（2026-09-30 用户定）
2D 的人物 + 场景表演改用「会动的漫画书」：一页几个分格，镜头从第一格开始逐格呈现；每格是纸片分层（背景 / 中景 / 人物 / 前景），只做少量运动（视差、慢推、头发衣角微动、眨眼口型）。歌词写在对话气泡里；拟声字画在格子里；人物冲出格框 = 2D 转 3D。工具 kits/comic.js（#943）。
混合 3D（用户补充）：漫画页是 3D 空间里的纸，可倾斜、翻起、分层；3D 歌词 / 关键词从气泡或格子里弹出到纸面之上；格子里可嵌小块 3D 场景；3D 动效（粒子、火花、冲击波、光）跨格飞行、照亮纸面并投影。
首批考虑用在：主歌 1 手机聊天、Sydney 段、文字洪水开头、Gato 段。

## 七、脸与特写（2026-09-30 用户定）
3D 模型的脸修得再好也不用于特写：3D 只拍中远景（脸 ≤ 20% 画高、|yaw| ≤ 20°）；唱歌 / 表情特写全部用 2D 头部包（#942，7 角度 × 俯仰 × 表情口型，千问生成、分层、网格变形转头）。

## 八、3D / 2D / 漫画的分工（2026-09-30 用户定）
- 高难度的人物表演（拿手机、躺床上、和道具互动、细腻表情、被淹没挣扎）不用 3D：千问生成 2D 关键画 + 动态漫画页（v4-03b 那种形式）。
- 3D 负责：舞蹈（动捕）、跑酷/运动、远景/中景、世界和特效、数学图形。
- 唱歌特写：2D 头部包（head-turn.mp4 那种，用户认可）。
