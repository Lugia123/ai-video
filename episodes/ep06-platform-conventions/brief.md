# ep06：平台惯例不是字符串替换

- **标题（封面大字，待用户定）**：按 Ctrl+W 删个词，整个窗口没了？
  - 备选：①「把 Cmd 全换成 Ctrl，快捷键就坏了一片」 ②「每个键，先问一句：归谁管？」
- **封面画面**：一只手指按着大键帽「Ctrl+W」，旁边纸质黑窗口正「啪」地合上、被抽走，橙色方块小人伸手去拦，头顶一个大「？」。视频前 3 秒兑现同一个画面（0s 光标停在打错的词后 → ~1s 按下 Ctrl+W → ~2.5s 窗口合上）。
- **一句话目标**：看完这集，观众知道把快捷键从 Mac 搬到 Windows 不能「Cmd 换成 Ctrl」一换了事，要先弄清每个键在新平台上归谁管——软件、黑窗口里的程序、还是系统。
- **受众**：对软件开发好奇的初中生及以上；做跨平台客户端的开发者也能看。旁白按初一阅读水平写，口吻学 ep01/ep02 用户定稿。
- **时长**：目标 90–140 秒。旁白 13 段、约 523 字（「Ctrl+W」等按字母计，偏多）。按 4.5 字/秒 + 句间 0.6 / 段间 1.2–1.5 / 问句 +0.3 / 系列字卡 2 / 结尾 5.6 秒粗估 ≈ 148 秒；按 ep02 实测校准（同算法 149.9 → 实测 123.66 秒）**≈ 122 秒**。横版 1920×1080 / 30fps。
- **视觉风格**：沿用 ep01/ep02（纸质 UI + 橙色方块小人 + `assets/lib`）。主比喻：三块「地盘」（软件 / 黑窗口里的程序 / 系统），键帽落到各自地盘上。3 处运镜：①开场窗口合上被抽走；②从 Mac 横移到 Windows 键盘（Cmd → Win 被锁）；③推近方向键键帽、翻到背面看编号和标记。
- **配音**：千问 `qwen3-tts-instruct-flash` · 音色 Maia（同 ep01/ep02）。
- **素材来源**：`source/series-script.md`（下称「原稿」，复制自 ep01）第 6 集（:273–323）。只用原稿「事实核对」表（:307–320）里已核的事实。

## 事实清单

| # | 主张（旁白里的说法） | 原稿出处 | 原稿「事实核对」 |

| 4 | 非 Mac 分支用 Ctrl+Shift+字母，是唯一没被占的命名空间（旁白「唯一一块还没被占的地盘」） | :287、:314（`keys.md:1482`、`:1596`） | ☑ 已核 |

旁白只保留一组数字：**八十五个 vs 七十二个**（「小键盘上的 6」是键名，不算数字）。keycode/mods 十六进制只留在画面上或不用。

**未用素材**：原稿 :290 侧注「一个编译期开关没开，菜单就半中半英」（:320 已核，但核对表注明「此前提今天已不成立」，已被修掉）。放进来得加「曾经」，且跟快捷键主线关系弱，建议不放。

**需要用户确认的几处**：
1. **s01 钩子**「按 Ctrl+W 想删词，整个窗口关了」是**推演出来的场景**：原稿已核的是「Cmd+W→Ctrl+W 拿走删除前一个词」（:313），而「Mac 上 Cmd+W 是关窗口」属于通用常识，原稿核对表里没有这一条。场景用「想象一下」开头，没说 Polter 真出过这事。请确认这个钩子能用；不行的话退回原稿的「查找替换 Cmd→Ctrl、键盘一半变红」开场（冲击力弱一些）。
2. s04「你把它抢过来，人家就用不了了」是对「拿走删除前一个词」的口语化说法。
3. s09「用程序模拟按键时」——原稿是「发键时漏了它」，指自动化测试用程序发键，不是用户手按；请确认说法。
4. s10 输入法和 ep02 讲的是同一个 TSF，本集只一句带过，不重复 ep02 的故事。
