s01：想象一下：你在黑窗口里按 Ctrl+W，想删掉前一个词。啪，整个窗口关了。
s02：这就是把 Mac 上的 Cmd 键，一股脑换成 Ctrl 键的下场。快捷键不是换个字就完事，先得问一句：这个键，归谁管？
s03：一个键按下去，可能归三方管：软件自己、黑窗口里正在跑的程序，还有 Windows 系统。
s04：Ctrl 加字母，在黑窗口里早就有主了：Ctrl+C 是叫停正在跑的程序，Ctrl+W 是删掉前一个词。你把它抢过来，人家就用不了了。
s05：所以 Polter 在 Windows 上，改用 Ctrl 加 Shift 再加字母。这是唯一一块还没被占的地盘。
s06：Mac 上的 Cmd 键归软件用，搬到 Windows，对应的是 Win 键。可 Win 键，是系统的。
s07：两边的快捷键，连个数都不一样：Mac 版八十五个，Windows 版七十二个。只能一条一条地对。
s08：更离谱的是，连按的是哪个键，都会认错。Windows 认键看编号，方向键的编号，还多带一个小标记。
s09：用程序模拟按键时，漏了这个标记：右方向键变成了小键盘上的 6，Shift 还被系统摘掉了。看起来，就像是快捷键没绑好。
s10：输入法也一样。在 Mac 上，候选字的小窗口由系统替你摆好。在 Windows 上，系统反过来问你：这段字，在屏幕上哪儿？
s11：所以，平台的规矩不是一张对照表，而是一张“谁管什么”的地图。
s12：下次搬快捷键前，先把它们分成三列：归软件的、归黑窗口的、归系统的。
s13：回到开头那个 Ctrl+W：它没坏，它只是早就有主了。
