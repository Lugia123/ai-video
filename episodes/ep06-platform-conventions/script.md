## s01
旁白：想象一下：你在黑窗口里按 Ctrl+W，想删掉前一个词。啪，整个窗口关了。
画面：【钩子 0–3s】第 0 帧：纸质黑窗口里一行命令，光标停在一个打错的词后面；一只手指按下大键帽「Ctrl+W」。「啪」时整个纸窗口像书本一样合上、被抽走，小人伸手想拦，扑了个空，头顶一个大「？」。

## s02
旁白：这就是把 Mac 上的 Cmd 键，一股脑换成 Ctrl 键的下场。快捷键不是换个字就完事，先得问一句：这个键，归谁管？
画面：倒带：一个纸质「查找替换」框「Cmd → Ctrl」，点下「全部替换」，一整块纸键盘一半键帽变红。大字「这个键，归谁管？」。说完后 1.5s 无配音系列字卡：《移植不是翻译》第 6 集 · 平台惯例不是字符串替换。

## s03
旁白：一个键按下去，可能归三方管：软件自己、黑窗口里正在跑的程序，还有 Windows 系统。
画面：三个纸圈依次出现并贴标签「软件自己 / 黑窗口里的程序 / Windows 系统」；几个键帽悬在上方，等着落位。

## s04
旁白：Ctrl 加字母，在黑窗口里早就有主了：Ctrl+C 是叫停正在跑的程序，Ctrl+W 是删掉前一个词。你把它抢过来，人家就用不了了。
画面：键帽 Ctrl+C、Ctrl+W 落进「黑窗口里的程序」圈，各自冒出一张小纸条「叫停」「删前一个词」；软件的手伸过来想抢 Ctrl+W，纸条被扯掉一半。

## s05
旁白：所以 Polter 在 Windows 上，改用 Ctrl 加 Shift 再加字母。这是唯一一块还没被占的地盘。
画面：一张纸地图，上面几块地都插满了别人的小旗，只剩一块空地「Ctrl+Shift+字母」；小人把橙色小旗插上去。

## s06
旁白：Mac 上的 Cmd 键归软件用，搬到 Windows，对应的是 Win 键。可 Win 键，是系统的。
画面：【再抓回来 ~30%】运镜：从纸 MacBook 横移到纸 Windows 键盘；Cmd 键帽变成 Win 键帽，「咔哒」一声被系统的大锁锁住，落进「Windows 系统」圈。

## s07
旁白：两边的快捷键，连个数都不一样：Mac 版八十五个，Windows 版七十二个。只能一条一条地对。
画面：两列纸清单并排往下滚：左「Mac 85」右「Windows 72」，中间连线一条条对上，对不上的留红圈。

## s08
旁白：更离谱的是，连按的是哪个键，都会认错。Windows 认键看编号，方向键的编号，还多带一个小标记。
画面：镜头推近一个方向键键帽「→」，翻过来，背面贴着一个编号牌，编号牌角上别着一枚小小的标记夹子。

## s09
旁白：用程序模拟按键时，漏了这个标记：右方向键变成了小键盘上的 6，Shift 还被系统摘掉了。看起来，就像是快捷键没绑好。
画面：【大场面 ~55%】一只机械手按「Shift + →」，标记夹子掉在地上；「→」键帽在空中翻转变成小键盘的「6」，Shift 键帽被一只系统的手捏走。屏幕上的快捷键毫无反应，旁边冒出误导性的小纸条「快捷键没绑？」，再被红笔划掉。

## s10
旁白：输入法也一样。在 Mac 上，候选字的小窗口由系统替你摆好。在 Windows 上，系统反过来问你：这段字，在屏幕上哪儿？
画面：【再抓回来 ~75%】左右分屏：左边 Mac，候选框自己贴到光标旁；右边 Windows，系统气泡冒出「这段字在屏幕上哪儿？」，软件举起一个量好的框回答，候选框这才落下。

## s11
旁白：所以，平台的规矩不是一张对照表，而是一张“谁管什么”的地图。
画面：一张「Cmd → Ctrl」的对照表被卷起，展开成一张地图，三块地盘「软件 / 黑窗口 / 系统」，每个键帽插在自己的地盘上。

## s12
旁白：下次搬快捷键前，先把它们分成三列：归软件的、归黑窗口的、归系统的。
画面：白板三栏「归软件 / 归黑窗口 / 归系统」，键帽便签一张张分进去。

## s13
旁白：回到开头那个 Ctrl+W：它没坏，它只是早就有主了。
画面：【收尾】回到开头的黑窗口：按下 Ctrl+W，这次打错的那个词被删掉，窗口好好的；Ctrl+W 键帽上挂着「黑窗口里的程序」的名牌。说完停 ≥2.5s，结尾字卡 ≥2.5s，干脆结束。
