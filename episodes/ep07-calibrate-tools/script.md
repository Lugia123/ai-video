## s01
旁白：一个窗口被弹窗挡住，整整一百五十二秒动不了。检测工具却打了个绿勾：没卡死。
画面：【钩子】第 0 帧：明亮的纸质 Windows 窗口，正中压着一个灰色弹窗；右上角纸条计时器飞快滚动「0 秒 → 152 秒」，窗口里的光标一动不动。「却打了个绿勾」时，旁边一块纸仪表「啪」地盖上一个大绿勾，下写「没卡死」。大字「挡住 152 秒 · 工具：没卡死」（放在窗口下方空白处）。

## s02
旁白：测试说通过，不一定真没事。也可能是你的工具换了个新平台，换了个法子在骗你。
画面：镜头拉近那个绿勾：原来是一张贴纸，贴在一块指针断了的纸仪表上；小人伸手把贴纸一角掀起。大字「绿勾是谁给的？」。说完后 1.5s 无配音系列字卡：《移植不是翻译》第 7 集 · 测试工具也要移植并校准。

## s03
旁白：Polter 做 Windows 版时，靠几件工具帮忙测。一件替你打字，一件替你截图，一件替你看窗口卡没卡死。
画面：三件纸工具依次落到桌上（一次一件）：键盘「替你打字」、相机「替你截图」、听诊器「看窗口卡没卡」。小人站在旁边挨个点名。

## s04
旁白：先说打字的那件。它有一种打法，把字母直接塞进去，绕开了输入法。拿它测输入法，永远看不到拼音变汉字。
画面：镜头推到键盘工具：字母块 e-c-h-o 从旁边一条「直通管道」直接滑进窗口，输入法小窗在一旁关着灯、被绕过去。「永远看不到」时，输入法小窗上打一个灰色问号。

## s05
旁白：换成一个键一个键地按，在中文输入法下打 echo。屏幕上蹦出来两个字：恶臭。
画面：【再抓回来 ~25%】切换开关拨到「一个键一个键地按」；拼音 e-c-h-o 一键一键按下，光标旁弹出候选框，「啪」上屏两个大字「恶臭」。小人捂鼻子后退一步。字幕「echo → 恶臭」。

## s06
旁白：别笑，这可是好消息。它证明这回打的字，真的经过了输入法。
画面：小人愣一下，随即竖起大拇指；「恶臭」两字下方画出一条路径：键盘 → 输入法 → 屏幕，路径亮绿。字幕「= 它经过了输入法」。

## s07
旁白：这招在科学实验里叫“正对照”：先给仪器一个明知有问题的样本，看它认不认得出来。认不出问题的仪器，它说没问题，也不作数。
画面：纸质实验台：一支标着「明知有问题」的样本试管放进纸仪器；仪器亮红灯——认出来了。另一台仪器对同样的试管毫无反应，它的「没问题」绿灯被划掉。大字「正对照」，小字「先喂一个明知有问题的样本」。

## s08
旁白：再看判卡死的那件。开头那一百五十二秒，它问的其实是：窗口里的消息，还传得动吗？
画面：回到开头那个被弹窗挡住的窗口。听诊器贴上去，冒出一个问句气泡：「消息还传得动吗？」。窗口里一串小纸信封在弹窗和窗口之间来回跑。

## s09
旁白：弹窗自己也在不停地传消息，所以答案永远是：传得动。它没说错，只是回答的，不是你想问的那个问题。
画面：【再抓回来 ~50%】镜头拉远：信封其实全是弹窗自己在传，窗口本身一动不动。仪器回「传得动 ✓」；旁边另一个气泡写着你真正想问的：「人还能用吗？」——两个气泡中间画一个不等号。大字「答对了，但不是你问的那题」。

## s10
旁白：截图那件更狡猾。它说图是原尺寸，其实只有六成大。照着截图去点，就点歪到了别处。
画面：【再抓回来 ~70%】相机工具吐出一张截图，标签写「原尺寸」；截图叠到真屏幕上，明显小一圈，标出「只有六成」。小人照截图上的位置去点，光标落在隔壁位置，红色小叉。字幕「说原尺寸，实为六成」。

## s11
旁白：还有一种骗法，连工具都不用：在 Mac 上跑测试，全是绿的。可专给 Windows 写的那部分代码，在 Mac 上根本没被编译过。
画面：Mac 纸电脑上一排测试全绿；镜头翻到背面：一叠标着「Windows 专用」的代码纸被一条「只在非 Mac 上编译」的纸带封着，灰色、从没被碰过。字幕「Mac 全绿 ≠ Windows 编得过」。

## s12
旁白：所以，每件测试工具上岗前，先准备一个明知会失败的样本，喂给它。
画面：三件工具排成一排，小人给每件喂一张红色「明知会失败」的样本卡；三件依次亮红灯。

## s13
旁白：回到开头那个绿勾：先看它红一次，再信它的绿。
画面：【收尾】回到开头那块仪表：小人先喂红卡，仪表红一次；再撕掉贴纸，换上一个真的绿勾。大字「先看它红一次」。说完画面停 ≥2.5s，然后结尾字卡 ≥2.5s，干脆结束。
