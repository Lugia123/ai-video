# ep07：测试工具也要移植并校准

- **标题（封面大字，待用户定）**：卡死两分半，工具说没事？先让它红一次
  - 备选：①「测试全绿，可能是工具在骗你」 ②「打 echo 出来“恶臭”，为什么是好消息？」
- **封面画面**：一块指针断了的纸仪表上贴着一张大绿勾贴纸，贴纸一角被橙色方块小人掀起，露出底下的红色；旁边纸窗口被灰色弹窗压着，计时纸条停在「152 秒」。视频前 3 秒兑现同一个画面（计时滚到 152 秒 → 绿勾盖下）。
- **一句话目标**：看完这集，观众知道测试工具换了平台也会「说错话」，上岗前要先喂它一个明知会失败的样本，看它红一次，再信它的绿。
- **受众**：对软件开发好奇的初中生及以上；做跨平台客户端的开发者也能看。旁白按初一阅读水平写，口吻学 ep01/ep02 用户定稿。
- **时长估算**：约 135–140 秒（13 段，旁白约 470 字 ÷ 4.5 字/秒 ≈ 105 秒 + 句间 0.6 / 段间 1.2–1.5 / 问句 +0.3 + 系列字卡 1.5 + 片尾 5.6）。接近 140 上限；要压时长可删 s11（Mac 全绿，约 12 秒）。横版 1920×1080 / 30fps。
- **视觉风格**：沿用 ep01/ep02（纸质 UI + 橙色方块小人 + `assets/lib`）。三件工具做成三个纸道具：键盘（打字）、相机（截图）、听诊器（判卡死）。运镜：①开场从计时器推到绿勾、再推近发现是贴纸；②s09 从「信封在跑」拉远，揭示全是弹窗自己在传；③s10 截图叠到真屏幕上缩放对比。
- **配音**：千问 `qwen3-tts-instruct-flash` · 音色 Maia（同 ep01/ep02）。
- **素材来源**：`source/series-script.md`（下称「原稿」）第 7 集（:324–372）。只用原稿「事实核对」表（:362–370）里已核的事实。

旁白只保留两个数字：**一百五十二秒**、**六成**。「0 毫秒」「1.0」「2999」「14」均未进旁白。

**需要用户确认的几处**：
1. 标题「卡死两分半」：152 秒 ≈ 2 分 32 秒，标题取整说「两分半」，旁白里仍说「一百五十二秒」。如不想取整，可改备选①。
2. s08–s09 把「嵌套模态循环照样在派发消息、API 问的是消息派不派得动」说成「弹窗自己也在不停地传消息，所以答案永远是：传得动」。技术上是弹窗的消息循环在替窗口派发消息，比喻成立但更口语。
3. s09「只是回答的，不是你想问的那个问题」来自原稿可迁移清单 :348（按你想知道的那一句选仪器），属于原则表述，不是新事实。
4. s10「原尺寸」= 缩放 1.0，「只有六成大」= 实际 0.6；「点歪到了别处」对应原稿「点会点在别处」（原稿分镜说「隔壁标签」，旁白未采用这么具体的说法）。
