# 坏样本

回归检查的阈值要靠「真的出过问题的版本」来标定。规矩（总管 2026-10-07 定）：

**每次用户或总管指出一个真问题，修之前先把坏版本存一份到这里**，然后用它确认对应的检查会响（坏样本上不过、修好的版本上过）。没有坏样本的检查，阈值只是起步值，报告里要照实写。

每个坏样本一个子目录，名字 = `日期-检查id-一句话`，里面放：

- 能复现问题的最小素材（出问题的那一片贴图、那一版 `parts.json` 片段，或一张成片截图），不用放整个数据包；
- `NOTE.md`：谁在哪天指出的、原话、问题在画面上的位置、对应哪条检查、这个样本上检查的读数、修好后的读数。
